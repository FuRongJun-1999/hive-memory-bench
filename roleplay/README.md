## K 面判法（v2.1，现位于 `persona-consistency/tools/score_k.py`）

```
T1  |正说均分 - (6 - 反说均分)| <= 1
T2  |round1 正说均分 - round2 正说均分| <= 1
T3  |round2 正说均分 - 换问法均分| <= 1
TOL = 1.0 + 1e-9   （必须带浮点容差）
```

三级全过记该方面通过；`pass_rate = valid_pass / valid_dims`。

### 区分力判据（v2.1 相对 v1 的改进）

```python
flat = len(set(v["p1"] + v["n1"])) == 1   # 正说与反说【原始分】全部相同才判无区分力
```

v1 是 `len(set(p1)) == 1`（只看正说），会把「正说全 5、反说全 1」这种**区分力最强**的情况误判为无区分力。v2.1 修掉了这个误杀。

## ⚠️ 已知缺陷（审核发现，尚未修复）

v2.1 只修了上面那一半，**另一半漏洞仍然存在**：

| # | 缺陷 | 表现 | 影响 |
|---|---|---|---|
| **1** | **逆极性模式放行** | 全 20 维都答「正说 1、反说 5」→ 原始分集合 `{1,5}` 长度 2 → 判有效；且 T1 算 `\|1-(6-5)\| = 0` 通过 | **纯唱反调被判 pass** |
| **2** | **跨维度模板化放行** | 全 20 维都答「正说 5、反说 1」→ 每维 `{5,1}` 判有效，但 20 维零离散度 | **固定模板刷分可通过** |
| **3** | **中性被误删** | 某维真实中立（都答 3）→ `len==1` 判作废、剔出分母 | **选择性偏差，抬高 pass_rate** |

### 建议的三层判据（未实现）

```
逐维层：保留 v2.1 的 set 判据
方向层：加 T1′ 要求「正说均分 > 反说均分」（堵逆极性）
跨维层：要求 20 维正说均分序列整体方差非零（或唯一值数 ≥ 阈值），否则整卷判「模式化作答」，单独报告而非混入分母
中性层：均匀 3 分单独归类为「中性一致」，不进 pass 也不进无效
```

## ⚠️ 读数表述约束

`persona-consistency/results/K_v2_readings.json` 是**各家聚合比例**（9/20、17/20 这类）。引用时必须遵守：

1. **分析单位是 20 个维度，不是 300 次调用**——调用次数只压缩维内噪声，不压缩维数抽样误差；
2. **n≈20 时 95% 区间宽约 ±20pp**，`plain-baseline 45.0%` 与 `dsh-world 85.0%` 的 40pp 差距**在区间边缘**；
3. **不得写「显著优于 / 领先」**，只能写「观测差距，逐维数据待导出后检验」；
4. **没有逐维分数就做不了 McNemar**——它需要同一组 20 维在两系统下对齐的 pass/fail 四格表；
5. 各家 `valid_dims` 在 16–20 之间不等，**分母不一致时直接比比例本身有偏**。
