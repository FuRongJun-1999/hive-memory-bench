# 判分可靠性 v1.0：判官会不会判错？我们怎么知道

> **一句话：本库不用单一判官。** 三次实测里，两次语义判官的一致率完全不可用，
> 唯一一次"看起来可用"的一致是**尺度塌缩**造出来的假象（两名判官几乎都判"没问题"，
> 都说没问题当然一致）。现在所有语义判分都走四道防线，**并且判官自己要先过一关**。
>
> **协议已实装（可跑、含硬闸）**：`judge_audit.py`——锚自证（正确率 − 多数类基线 ≥ 15pp）、
> 一致率（同分/kappa → `可报值/只报序/不可测`，强制携带样本档位）、
> 「任一判官不合格 ⇒ 整批作废」（不合格时拒绝写入读数记录并非零退出）。
> 用法：`python judge_audit.py check <输入.json> --out systems/judge_audit.json`；
> 自检（含**定点变异用例**：人为把某判官锚正确率打到基线 +0pp，硬闸必须拒绝）：
> `python judge_audit.py selftest`。历史两轮的审计记录：`systems/judge_audit.json`。

## 一、为什么单判官不可用（三次实测）

| 批次 | 判的是什么 | 判官间一致 | 结论 |
|:--|:--|:--|:--|
| 一 | 承重（条目级重叠） | **0.20–0.375** | 不可用 |
| 二 | 接地判断（160 条） | 同分 94.4%、kappa 0.659 | **假一致**：零个 0 分，两名判官几乎都判"没问题"——**尺度塌缩** |
| 三 | 同一批 12 条的独立复核 | **同分 5/12 = 42%** | 不可用 |

**三次里只有一次一致率尚可，而那一次是假的。**
⇒ **凡涉及「语义质量」的判断，单一判官一律不可靠。**

## 二、判官的分歧是什么性质：从「系统性偏置」订正为「双向噪声」

第三批出现了 **7 条分歧全部同向**（一名判官全判降级、另一名全判维持）——
当时据此得出「**错误不是随机的，是系统性偏置**」，并进一步推出
「系统性偏置不会因为人多而抵消，多数票仍然偏置」。

**这个结论已收回。** 查下去发现根因是**我方派单缺陷**：那批 23 条里有 11 条
不属于该判官拿到的材料范围，**它拿不到那 11 条的依据**，判词锚点被自己不知道的缺材料拖偏。

按协议重做（同材料、盲混、掺固定锚）后：

| | 判官 A | 判官 B |
|:--|--:|--:|
| 锚（已知条目）正确率 | 66.7% | 75.0% |
| 被测方正确率 | 50.0% | 58.3% |
| 判官间 | 同分 17/24 = 70.8%、kappa 0.400 | |

**分歧 7 条：降级→维持 4 条、维持→降级 2 条、丢弃→降级 1 条——双向。**

⇒ **订正为**：判官间的错**是双向的、近似随机噪声**，不是单向偏置。
这不改变「必须多人」的结论（kappa 0.400 仍远未达标），改的是**对这种错的性质的描述**——
**也说明「材料给全」和「掺锚」不是形式主义：缺材料会直接改变判官的宽严档位。**

## 三、四道防线（现在的做法）

### 1. 机械先决——能机判的，绝不交给判官

| 判什么 | 交给谁 |
|:--|:--|
| 引文可定位性、字段自洽、双向约束、白名单比对 | **机械**（不依赖判官，可复现） |
| 「抽掉它结论是塌还是换条路」这类**依赖关系** | **判官**（必须多人，按本协议） |
| 「改道后的下游紧邻是否真的成立」 | 判官（目前无机械锚，实测最不稳） |

**判官的不稳，主要来自我们让他们判了本可以机判的东西。** 所以第一步永远是把可机械化的
全部机械化——不是为了省事，是为了少给判官留自由裁量的面。

### 2. 盲混 + ≥2 名判官，各自独立

> **协议底线 vs 实跑配置**：本节写的是**最低协议**（≥2 名、盲混、互不可见）；
> 本项目对外主对比面的**实际配置＝3 判官 × 温度 0/0.5/1**（见
> [`多语料复现_v1.0.md`](多语料复现_v1.0.md) 与 `systems/readings.json`「零材料对照.口径」）。
> 两个数字不冲突：一个是门槛，一个是执行值。

- 同一批判词**打乱来源、剥掉题号与来源标签**再看（实测样本构成会拖动判官锚点）；
- 两名判官**不得读对方判词**、不得互相引用；
- 两人**必须拿同一份材料与同一张判据**（否则差异里混进了信息差，不可归因）。

### 3. 固定锚，且**锚必须先自证**

每批判词掺入**固定比例的已知条目**（如答案键条目）当加严标尺。锚的作用是让
「这一次判官偏严还是偏松」**可读出来**。**锚自己要先过一关**：

```
基线 = 锚里占比最大的那一档的频率（6 root / 6 support ⇒ 基线 50%）
判官在锚上的正确率 − 基线 ≥ 15 个百分点  ⇒ 该判官合格
任一判官不合格                          ⇒ 该批作废（或只采信合格那名，并声明）
```

**这一关抓出过什么（两次真实翻车）**：

- **退化策略**：某判官在锚上只对 **58%**，而**"全判多数类"的基线就是 50%** ⇒ **只高 8pp，基本等于瞎猜**。
  同批另一名判官 75%（+25pp）。而两人在**同一批 33 条**上的同分率是 **81.8%、kappa 0.552**
  ——**看起来"达标"，其实是其中一名在用退化策略。** 只看一致率会放过它。
- **尺子本身是歪的**：某批锚的读数（36.4%）**低于被测方**（90.9% / 81.8%）——锚垫底。
  查下去**不是被测方差，是答案键差**：一条规则被反复挂在 6 条结论上，
  判官指出它"只是社会底色，抽掉后走向照旧"；另一条是**贴错条**（把同章紧随其后的另一条
  时长规则当成了本条）。**没有这一关，倒挂会被误读成"被测方表现好"。**

### 4. 聚合规则

```
先算判官间一致率。
  达标（kappa ≥ 0.6 或 严格同分 ≥ 80%）
      ⇒ 取均值，并报告区间（不报单点）
  不达标
      ⇒ 绝对水平判「不可测」，不报数
      ⇒ 若 ≥2 名判官在同一对比的**方向上一致**（如都判 A 组 > B 组）
         ⇒ 可报「序」，但必须注明一致率未达标、幅度不可信
      ⇒ 方向不一致 ⇒ 连序也不报
```

**禁止**：单判官出结论；跨批次直接比绝对水平（只能同一次内比）。

## 四、三条纪律级教训

1. **报一致率必须同时报样本的档位构成。** 同一切点上的同一批判官：
   退化样本（锚 8 高 / 4 低）给 **kappa 0.939**、均衡样本（6 / 6）给 **0.552**——
   **换样本就把"优秀"打成"勉强"**。单样本单次读数不得当稳定结论。
2. **锚要分层抽，不能随机抽。** 曾抽到 **11 : 1** 的锚——"全判多数类"就能得 92%，
   锚失去区分力。⇒ 各档等量。
3. **分工写死**（见防线 1）。判官只判机器判不了的。

## 五、边界（必须与读数一起看）

1. **判官仍然是 LLM**，不是一个独立的第三方专家层。
2. 本项目当前的层级是 **机械 → LLM 判官（多人）→ 作者裁决**；
   **没有**独立的人类专家标注层。所以跨系统比较只在「同一批判官、同一次」内成立。
3. 一致率达标 ≠ 判对。它只说明"这批上两名判官读得一致"，**正确性仍取决于锚怎么造**。
4. 本报告里部分读数取自**一套未公开的留出题集**（其题面与答案键不公开）——
   读者能复现的是**方法与门槛**，不是那些具体条目。

## 六、怎么在自己的评测上照做

1. 先把能机判的写成代码（可定位性、字段、格式），**别拿去问判官**。
2. 判官 ≥2 名，同材料、同判据、盲混、互不可见。
3. **掺分层锚**，并按上面的量化门槛**先验判官**，不合格就作废。
4. 报一致率时**连样本档位一起报**；不达标就报「不可测」或只报序。
