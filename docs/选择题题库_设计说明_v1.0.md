# 选择题题库 v1.0（150 题）· 设计说明

> **一句话**：本批题的唯一价值是**判分环节零噪声**（字符串相等，不经模型/人工，可复现、可跨系统横比）。**不等于测量零噪声**——四选一随机基线 25%，引用时须同时报基线并做二项检验。
> 代价是它只能测「认不认得」，测不了「说不说得清」。

---

## 一、为什么要加这批题

本仓现有 184 题（主轮 92 ＋ 干预轮 92）是**论述题**，判分依赖判分器（≥2 判官 + 锚自证）。
做过三版判分对照，同一批答案的读数差异极大：

| 判法 | 千问检索 | 结构化记忆 |
|---|---:|---:|
| 二字组覆盖率 | 55% | 18% |
| LLM 判官 | 87% | 19% |
| **ABCD 选择题** | **99%** | **83%** |

**同一个系统、同一批答案，只换判法，差 65 个百分点。**
其中「二字组覆盖率」对「答对了但换了说法」极不公平（把 55 判成 99 的差距）；
「LLM 判官」有同源偏好。**只有选择题是零噪声的。**

所以本批题不是要替代论述题，而是提供一个**判分可信的锚**：
任何系统在这批题上的读数，换谁复核都一样。

---

## 二、题是怎么造的

```
① 从四类语料抽「可提问的事实」（每条带原文出处 offset）
② LLM 把事实改写成「没读过原文的人会怎么问」（禁专名、禁答案词）
③ 生成 1 个正解 + 3 个近似干扰（同句式、只改关键信息：数字/人名/时间/官职）
④ 人工核对：正解的事实要点必须能在原文找到出处（**不要求 `fact` 字段本身逐字**，见 §六.4）；干扰项必须事实错误
```

**干扰项示例**（只改一处）：

| | 内容 |
|---|---|
| 正确 | 毕业后考上县派出所编制 |
| 干扰 | 毕业**前**考上县派出所编制 |
| 干扰 | **入学前**考上县派出所编制 |
| 干扰 | **实习期**考上县派出所编制 |

**这种干扰项保证：不读原文、只凭语义相似度猜，命中率接近 1/4。**

## 四、五个基线读数（选择题判分）

> **引用口径**：四选一随机基线 **25%**（150 题全猜期望对 37.5 题）。下表报准确率，**横比时必须同时报 25% 基线与样本量并做二项检验**；只报准确率不给基线是不成立的表述。

> **「零噪声」的限定**：指**判分环节**（`pick == answer`，不经模型/人工）。**不表示「测量零噪声」**——题目本身仍有干扰项质量、覆盖（只单跳）等测量误差。


| 方案 | 选对 |
|---|---:|
| 直喂原文（4 万字/份，秦吏 39 题）| **100%** |
| 千问-2560 检索 top-10 | **99%** |
| BM25（二字组）| 95% |
| OpenViking | 92% |
| 结构化记忆（470 条六要素，公平版）| **83%** |

**两个可直接引用的结论**：

1. **单跳题上，词法（BM25 95%）几乎追平语义（千问 99%）**——差距只有 4 个点；
2. **结构化记忆「认得出、说不出」**：选择题 83%，同一批题开放式只有 19%。

## 五、与「多跳」的分工（重要）

本批 150 题**全部是单跳**（答案落在某一段内）。多跳请用主轮/干预轮的线索题与因果链题。

我们另做过的多跳对照（供参考，不在本 PR 范围）：

| 方案 | 多跳覆盖 |
|---|---:|
| 纯向量 top-10 | 0.03 |
| 结构化定位 + 回源 | 0.07 |
| 灵枢多路 20 条 | 0.19 |
| 灵枢 50 条 | 0.35 |
| **+ 按章节重排** | **0.40** |
| **+ 补 n±1 邻接章** | **0.51** |
| （对照）直喂全文 6 万字 | 0.46 |

**⇒ 单跳靠检索够了（99%），多跳必须补结构（0.51 才追平/超过直喂）。**

## 六、边界（诚实清单）

1. **只测「认出」，不测「复述」**——两件事差 64 个点（83% vs 19%）；
2. **全部单跳**，不覆盖跨段关联/因果链；
3. 干扰项由 LLM 生成，**只改关键信息**，属较严格档；
4. **`fact` 是「改写概括」，不是逐字引文**——它忠实复述原文事实要点（如「您当前信用点：0（新成员初始值）」→「陈默当前信用点为 0，是新成员初始值」），可用于核对事实，**不能用于逐字定位**；中位 29 字、最长 66 字。完整逐字引文本版未做；
5. 语料含他人作品（秦吏/毛选），`fact` 仅为短句引用，**不随题公开原文**；
6. 全部单次运行，无重复实验；
7. **可核范围只有 47%**：蜂巢指南 38 题（`corpus/`）与真实对话 32 题（`e2e/corpus/`）共 70 题的 `fact` 可回原文核对，
   已逐一核过（蜂巢 37/38、对话 32/32 有依据）；秦吏 39 ＋ 毛选 41 共 80 题因他人作品版权不公开原文，
   **第三方无法复算**，只能依赖出题时的原文核对。引用读数时须记住这个 47/53 的划分。

## 七、怎么用

```bash
# 1. 系统读题（只给 question + options，不给 fact）
# 2. 输出 sut/out/<qid>.json：{"qid":"S-001","pick":"B"}
# 3. 判分：pick == answer 即通过（无判官）
```
