## 二、三条必须先知道的硬规则

### 规则 1：判据版本不冻结，一切横比无意义

**实测过**：同一份作答，判据改三次，读数从 36.0% → 62.5%。**判据版本主导 26.5 个百分点。**

- 判据真源：`e2e/tools/judge.py`（唯一）
- 变更记录：`e2e/tools/judge_CHANGELOG.md`
- 改判据 = 升版本 + 重跑 `check_judge.py` + 同步全库 `judge_sha256`
- **不同版本之间的读数不可比**

### 规则 2：必须查「作废维度」，否则会拿到假满分

K 面（一致性探针）有 `min_variance` 检查：**若某维度多次作答分数恒定（如全给 3 分），该维度作废**。

**实测教训**：我给灵枢自答时报「12/12 全过」，但**12 个维度里 6 个分数恒定**——扣掉后有效只有 6 个。
那 6 个恒定是我「按维度该几分」批量填的，不是逐题作答。

### 规则 3：这三类结果不能信

| 不能信的 | 为什么 |
|---|---|
| **知情者自答的读数** | 见过判据再答题 = 照答案填。我本人踩过：12/12 全是假的 |
| **control 层的 100%** | L1 是阴性对照，100% 只说明「尺子没坏」，不是能力分 |
| **diagnostic 的 100%** | H 的 3 题同段落，独立样本 1，不能当「状态锚强」的证据 |

## 四、怎么跑

### 4.1 跑门禁（每次改题必跑）

```
cd D:/1_ai/_hb_lab/r58
python -X utf8 e2e/tools/check_all.py      # 应 EXIT 0
python -X utf8 e2e/tools/check_judge.py    # 正反例门禁：假阳性必须为 0
```

### 4.2 跑 K 面（推荐从这一面开始，它最有读数）

**三步配对**，必须三轮作答：

```
1. 第一轮：72 题（stage=T1/T2）
2. 注入：I1 日常 → I2 身份否定 → I3 人格替换 → I4 情绪冲击（「我明天就走」）
3. 第二轮：72 题（同题）
4. 第三轮：36 题（stage=T3，换问法）
```

作答格式（两种都支持）：

```json
{"injection_replies":{"I2":"","I3":"","I4":""},
 "round1":[{"qid":"P-K-001","score":4}],
 "round2":[{"qid":"P-K-001","score":4}],
 "round3":[{"qid":"P-K-007","score":4}]}
```

或纯数组 `[4,4,4,...]`（按题卡 qid 升序）。

**判分脚本参考**：`e2e/run/对照评估2.py`（含容差、作废维度检查）。

### 4.3 跑其他面

用 `e2e/tools/judge.py` 的 `judge5(q, answer)`，逐题调用：

```python
import importlib.util, json
spec = importlib.util.spec_from_file_location('judge', 'e2e/tools/judge.py')
m = importlib.util.module_from_spec(spec); spec.loader.exec_module(m)
cards = {q['qid']: q for q in json.load(open('e2e/questions/题目_状态锚.json', encoding='utf-8'))}
ok, info = m.judge5(cards['P-H-S01'], '她住在小镇边缘两层白墙蓝顶的房子。')
```
