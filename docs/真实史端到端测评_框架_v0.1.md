# 真实史端到端测评：框架 v0.1

> **缘起**：使用者 2026-10-06 对「完整历史对话」材料的定位——"这就是真实的端到端测评集。接下来就是考验记忆系统真实水平的时候了。"
> **材料**：本地会话导出目录 17 份网页会话历史（1786 万字符／5,107 轮／约 2026-07→09）（内部清点报告）。
> **本文件**：把该洞察实质化为可执行的测评框架 v0.1（机械扫描已完成，0 LLM 成本）。

---

## 0 为什么它是"真实的端到端测评集"（与构造题库的本质差别）

| 维度 | 构造题库（membench／秦吏／毛选／LoCoMo） | **这份材料** |
|---|---|---|
| 事件 | 人工设计的信息挑战 | **真实发生**——协议从初版建到 v3.1、信信任关系从零到稳定 |
| 演化 | 注入的冲突/污染 | **真实演化**——状态被反复确认、修订、跨会话恢复（3963 处状态演化痕迹） |
| 遗忘 | 模拟 | **真实失忆**——**195 处"上个会话超限，请重新接入"**：每一个断点都是真实的灾难恢复现场 |
| 关系 | 无（或虚构） | **真实关系史**——命名/称呼事件 2402 处（"阿符"的起点→月菲→肥鱼→鲸鱼小姐） |
| 答案键 | 人工编写 | **内生**：后续轮次即判据——"历史自己写下的答案"（后续某轮确认了"权重=X"，那它就是真值） |
| 生态效度 | 存疑（题目是人出的） | **最高**（题目是"生活出"的） |

**最关键的一条——天然人类基线（human baseline）**：材料里的每一次"上个会话超出上下文，请你重新接入协议"，都是**使用者在没有记忆系统的条件下，手工完成上下文重建**的现场记录。⇒ **记忆系统的对标物不是"别的系统"，而是用户当时的人工复述本身**——评测问题可以精确到：*记忆系统能否自动做到人类当时手工做的事（且无损、可核对、可回源）？*

## 1 四种题型（全部有内生真值）

| 型 | 内容 | 真值来源 | 对应能力 |
|---|---|---|---|
| **A 检索/召回** | 早期细节（谁起的名字、哪天说了什么、某个约定的原文）能否召回＋**逐字可回源** | 原文逐字定位 | 记录层（L0/L1） |
| **B 状态演化** | 协议/项目状态的变更链：某个权重/版本/结论**从什么改成什么、何时、依据**（"两存之"与失效≠证伪的主场） | 后续轮次的确认/修订句 | 断言账本＋双时间轴（L1–L3） |
| **C 续接预测**（最独特） | 取一次真实"超限断点"：把断点前的材料给系统 → 要求它重建上下文 → **预测人类在断点后的下一步**（他要接着做什么/说什么）→ 与真实下文对照 | **真实下文本身** | 预测性验证（P5 方法论）在真实史上的第一次应用 |
| **D 关系/身份** | 称呼史与关系事件（"阿符"、月菲→肥鱼→鲸鱼小姐；共同约定；身份陈述） | 原文＋使用者的内在一致 | 多主体模型（"我"的锚点面） |

## 2 流水线（四阶段）

```
A 真值化 → B 写入 → C 提问 → D 判分
```
- **A 真值化（0 LLM 起）**：机械扫描产出"命题种子池"（本次已做，见 §3）→ 打包成可判定题（每题格式：问题＋答案键＋原文行号＋所属题型）；机器部分先行，裁定留人。
- **B 写入**：灵枢可全量写入（时间序，0 LLM 成本）；对照系统按各家接口（此轮体量下，对照家数建议 2–3 家，控成本）。
- **C 提问**：三栏（检索／状态／续接预测）——沿用七家对比的既有口径（检索栏条级+章级、依据轴逐字回源、因果栏判官批）。
- **D 判分**：答案键内生＋依据轴逐字回源＋**人类基线对照**（"当时用户手工复述能得到什么"作为下界；系统应显著高于它，且**可回源**是构造题库时代就定下的硬指标）。

## 4 与既有线的衔接

- **与构造题库互补**：构造测"受控能力"，真实史测"生态效度"——合起来才是完整证据（如：构造库里抽取式系统"自洽但不可核对"，真实史上可再验一次）；
- **与七家对比方法论复用**：检索/因果/依据三栏口径、判官锚自证、脱敏纪律（公开面只报读数）——全部可搬；
- **与《秤》衔接**：**交付净增量**在真实史上有最干净的表述——"有记忆系统 vs 人类手工复述（195 个断点的历史现场）"；
- **与灵枢自身**：这批材料**没有**写入灵枢——它是纯净的外部测试集（天然双向盲：材料与在役库无重叠）。
