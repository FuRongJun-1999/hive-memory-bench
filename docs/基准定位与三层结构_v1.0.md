# 基准定位与三层结构 v1.0

> **定位：一个以长文本世界模型为载体的中文 LLM 基准——测量「跨章节因果记忆 ＋ 证据保持 ＋ 干预后因果边界维护」。**
> 本文说明它为什么不是一个"long-context QA"，以及三层各测什么、读数在哪。

---

## 1. 它测的不是"检索那句话"

材料是一部 23 章、约 6.1 万字的小说——小到能被长上下文模型整本读入，大到任何一章都不足以回答跨章问题。
在这个**受控的小型世界**里，本基准让被测方做三件性质不同的事：

```
Layer A  世界模型重建      从全部材料构建一致的世界模型（跨章因果链）     ← 主轮 92 题
Layer B  因果干预          抽掉/改变一个前提后，划出因果边界（什么倒、什么照旧） ← 干预轮 92 题
Layer C  证据落地          每个判断能被回源核对（逐字引文可定位）        ← 依据轴 / 引文保真读数
```

**三层相关，但不可互相代理。** 一个模型可以串起因果链（A 强）却写不出可核对的引文（C 弱）；
可以复述世界（A 强）却划不出干预边界（B 弱）；抽取式记忆系统甚至可以三层中 A/B 都不差、
C 结构性为 0。把三层混在一起统称"memory"，在测量学上会被直接问 **construct validity**——
所以我们不混。**每篇文档只报自己那层的读数。**

### Layer A · 世界模型重建

- **测什么**：读懂之后能不能把散在各章的信息串成因果链（而不是检索-拼接）。
- **已测读数**：主轮 92 题（[README 成绩表](../README.md)）＋基线分析
  （[`基线分析_v1.0.md`](基线分析_v1.0.md)：参考实现 66.3%、无记忆系统 37–49.5%）。
- **注意**：主轮答案键已公开（逐题可复核），也因此**可能被训练污染**——跨模型横比不看主轮。

### Layer B · 因果干预

- **测什么**：删掉/改变世界模型的一块之后，**哪一层失去依据、哪一层照旧**。
- **已测读数**：[`干预轮对比_v1.0.md`](干预轮对比_v1.0.md)（92 题盲测面，答案键不公开）；
  指标定义与两类错误见 [`因果边界保持_v1.0.md`](因果边界保持_v1.0.md)。
- **现状**：**无一家（含自测基线）给出两层齐备的边界**——多数被测方只答出"失据层"侧的后果清单、未划出"照旧层"（两个互不知情的判官组独立报出）；GPT-6 与 Gemini 3.7 形态另有其病（缺"失据层"，见 [`因果边界保持_v1.0.md`](因果边界保持_v1.0.md) §3②）。**该面无人接近饱和**。

### Layer C · 证据落地

- **测什么**：每个判断是否携带**能在原文本里逐字定位**的引文（证据轴）。
- **已测读数**：[`三分数对照_v1.0.md`](三分数对照_v1.0.md)（C 栏细分：精确/近似/编造）、
  [`记忆系统对比_v1.0.md`](记忆系统对比_v1.0.md)（六家记忆系统：逐字率／可回源率／反幻觉）、
  [`压缩的代价就是因果丢失_v1.0.md`](压缩的代价就是因果丢失_v1.0.md)（压缩丢的"对面那一块"）。
- **本层的结构性发现**：改写路线（抽取式记忆）在 C 层结构性为 0 可回源；
  原文路线 ≈100%。**推理可借模型，依据必须靠记忆。**

## 2. 本基准的论点（供引用）

> **长文本记忆系统的核心问题不是检索相关性，而是保持"支持因果推理所需的结构性证据"；
> 语义压缩可能系统性地破坏跨章对立关系（丢的不是随机信息，是"对面那一块"）；
> 而干预测试可以诊断模型是否真正保持了因果边界，而不是只会流畅复述。**

这条论点由三组独立实验共同支撑：记忆系统四栏对比（Layer C）、压缩代价实验（Layer C→B）、
零材料对照（[`零材料对照_因果归因_v1.0.md`](零材料对照_因果归因_v1.0.md)：证明"推理"来自模型本身、
记忆系统的价值在"依据"）。

## 3. 相关工作（两篇，已核实）

| 工作 | 要点 | 与本基准的关系 |
|:--|:--|:--|
| **Causal-LoCoMo / CMI**（arXiv 2605.17641，2026-05） | 主张按"记忆对答案的因果影响"选择记忆（受控干预下的有用性），反对"语义相似度＝有用" | **互补**：它解决"**怎么选**记忆"；本基准量化"**选的代价**"（压缩丢失的方向性）与"**怎么测**"（四栏读数）。本基准发现的"对面那一块"正是它要过滤的 harmful memory 的成因机制 |
| **WhatIfBench / PRISM**（arXiv 2608.27953，EMNLP 2026） | 开放域长程反事实诊断（220 题），语义因果图评分；报告 premise drift、topology fragmentation；最强模型 64.62% | **同方向对照组**：开放域 vs 本基准的**受控世界**；它的两个失败模式 ≈ 本基准的**干预失明 / 过度传播**（见[因果边界保持](因果边界保持_v1.0.md) §2） |

## 4. 边界声明（本基准**不**主张什么）

- **不主张三层的分数可以互相换算**（分母不同、设计不同）。
- **不主张主轮读数可跨模型横比**（答案键公开、存在污染面；一律只取干预轮）。
- **不主张 92 题＝92 个独立样本**（见 [`题目独立性_v1.0.md`](题目独立性_v1.0.md)：有效样本量按 ≤24 的量级理解）。
- **不主张"零材料高分 ⇒ 记忆系统无用"**：零材料对照的适用范围＝"题面已复述局面的截断外推题"；
  对"必须记住后文才能答"的记忆型任务，材料的作用见[记忆系统对比](记忆系统对比_v1.0.md)的地基触达栏。
