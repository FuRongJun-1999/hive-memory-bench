## 一、项目一句话

## 二、核心教训（花了 6 轮实验才确认）

> **只要选项或陈述是自然语言，LLM 就能靠「语义自然度」猜对，测不出记忆。**

| 题型 | 闭卷（不给材料）| 随机基线 | 判定 |
|---|---:|---:|---|
| 五选一选择题（238 题，选项=长段落）| **82.8%** | 20% | ❌ 选项泄漏 |
| 判断题（叙事型陈述）| 87.5% | 50% | ❌ 陈述自洽可猜 |
| 事实组合型（4 选项=元素组）| **100%** | 25% | ❌ 最严重 |
| 多跳自然语言要点（92 题）| **69.6%** | ~5% | ❌ 真点读着自然 |
| **六元素判断题（476 条）** | **52.9%** | 50% | ✅ **≈随机，无泄漏** |
| **多跳六元素 rubric_92（单断言·平衡掩码）** | **50.0%（φ=0.000）** | 50% | ✅ **零泄漏，且开卷 87.1%** |

**唯一有效的格式**：六元素拼接（章节·人物·地点·事件·情绪·物品）+ 判断「是否符合原文」。
**关键**：元素是「无语义的标识」（章节号/人名/地名），模型无法靠连贯性猜。

### 已验证的读数（六元素 476 条，DeepSeek-flash 作答）

|---|---:|

| **差距** | **34.6 点** ← 这才是「记忆信号」|

## 四、rubric_92 是什么（最新产物，待验证）

把多跳题改造成「每题 **6 条**六元素要点（**3 真 3 假**）」，每条带 rubric：

```json
{
  "qid": "o001",
  "conclusion_elements": ["第2章…", "求知园", "同名同姓", ...],
  "points": [
    {"stmt": "第2章「巧合还是阴谋」 · 陈默 · 求知园 · 提交工作任务 · 忐忑不安 · 修复液",
     "answer": true,
     "rubric": {
       "required": [{"slot":"章节","value":"..."}, ...6项],
       "acceptable": {"人物": ["张明远","张老"]},
       "forbidden": [{"slot":"物品","value":"该章不含的真实物品"}],
       "interpretation": "一句话 + L行号"
     }}
  ]
}
```

**防泄漏三规则**：
1. 真点：六元素全部符合原文（情绪必须是**原文连续子串**，如「眉头一皱」，不能是推断词「决绝」）；
2. 假点：只错**一个**元素，其余五个**各自为真但不与任何真点重合**；
3. **孪生对 = 0**：任何真点与任何假点**至少差 2 个元素**（否则模型可比对「这两个必一真一假」反推）。

**实测：92 题 / 828 个真/假配对，孪生对 = 0，最小差异 5 槽。**

**判分**：每条要点答「是/否」，**6 条全对才算该题对** → 全蒙对概率 = 1/64 = 1.56%。

### ① 验证 rubric_92 —— ✅ **已完成（2026-11-09）**

> 完整报告：[多跳六元素rubric92_验证报告_v1.0.md](多跳六元素rubric92_验证报告_v1.0.md)

结论：**成立，且是目前唯一同时满足「零泄漏 + 可测记忆」的多跳题库**。读数（deepseek-flash，thinking=disabled，T=0，单次运行）：

| 口径 | 闭卷 | 开卷 | 记忆信号 |
|---|---:|---:|---:|
| **单断言 + 平衡准确率（推荐）** | **50.0%**（φ=0.000） | **87.1%**（φ=0.745，只给所引章节） | **+37.1 点** |
| 原设计 6 条一次判（整题全对 6/6） | 2.2%（p=0.657 vs 1/64） | 19.6%（给全文）| +17.4 点（不推荐，见下） |

整题全对 6/6（单断言口径）= 38/92 = 41.3%；分槽位开卷 85–91%，无短板。数据审计：真点 97.5% 六元素逐字可查、假点 100% 恰好错一槽。

**验证过程中修掉的三个坑（都写进报告 §5，别再踩）：**

1. **推理模型空响应**：`deepseek-flash` 现在默认开推理，不显式 `thinking={"type":"disabled"}` 时
   `max_tokens` 被 `reasoning_content` 吃干、`content` 恒空。上一轮 mh6 的「闭卷 0/92」就是空响应统计
   （552 条断言只解析出 28/36 条）。
2. **题序位置泄漏**：原 rubric_92 的 3 真 3 假只有 13 种排布，`TFTFTF`+`TTTFFF` 占 82.6%，
   slot1 88% 为真、slot4 仅 8.7% —— **只按位置猜就能远超 1/64**。已用平衡掩码重排
   （`rebalance_rubric.py`，种子 20261109），修后各槽位真点率 50/46/46/45/45/44、最热掩码 5.4%。
3. **开卷 prompt 污染**：把「即使没有原文」写进两条臂共用的尾句，会把开卷推向一律「否」
   （开卷·仅章真点命中 0.0%）。闭卷/开卷必须分开措辞。

**尚未做（交接）**：整题全对口径下的「开卷上限 ≥90%」没有达成，也未追求——该口径瓶颈是
「模型一次性核对 6 条」而不是记忆，改用单断言后开卷 87.1%。若坚持要整题口径的上限，需要开推理或分步核对。

**⚠️ 已踩过的解析坑**：

1. **prompt 措辞**：如果写「你没有原文」，模型会**拒答**（「我不能凭空核对」）。
   → 必须写「即使没有原文，也请凭印象判断」；
2. **输出解析**：要求模型按 `1: 是\n2: 否` 格式逐条输出，解析时用正则 `(?:^|\n)\s*(?:\()?\s*N\s*(?:\))?\s*[.、:：]?\s*(是|否)`；
   如果只要求「按顺序输出数组」，模型可能输出错位（曾导致 66 题解析失败 → 假读数 25%）；
3. **带 qid 重测**：第一轮没带 qid 无法排除顺序错位，重跑带 qid 才可信（两次读数接近才算数）。

## 七、出题纪律（给未来要改题/加题的会话）

### 真点

1. 六元素全部**逐字可查**于 evidence 所在章（±30 行窗口）；
2. **情绪必须是原文连续子串**——「眉头一皱」可以，「决绝」不行（那是推断）；
3. 原文没情绪描写 → 降级为**动作/状态**（「道谢」→「谢谢你派蒙」）；
4. 章节号要与语料 `## 第N章` 标题**逐字一致**（注意第18章是单 `#` 标题；`## 第N章` 只数出 22 章）。

### 假点

1. 只错**一个**元素，其余五个**各自为真但不与任何真点同槽同值**；
2. 错值必须是**原文真实存在的其它元素**（他章的章节/人物/地点/物品）；
3. **语法匹配槽位**：事件位=动词+宾语或状态描述（不能填名词如「陆军型号」）；
4. **孪生对 = 0**：假点不要从真点「只换一个元素」生成——那样每题出现两条只差 1 元素的孪生，模型可比对反推。

### 已知遗留瑕疵（不影响硬规则）

1. 个别假点把同章不同场景的地点与事件拼在一起（如「第9章·冒险者协会·解锁七天神像」两元素都在第9章但场景不同）；
2. 2-3 条假点施动者不匹配（去重约束挤掉了施动者匹配）；
3. 同义词差异**故意保留**（如「语气温柔」vs「温柔的语气」）——这是设计意图，考察 LLM 同义判断。

## 术语与必备列（2026-11-10 起）

题库只有三个角色，此前把它们混称「判官」是错的：

| 角色 | 干什么 | 备注 |
|---|---|---|
| **verdict 产出者**（作答/判定者） | 看材料输出「是/否」 | 七臂里是外部 LLM；系统自带判定则是系统自身的确定性核对 |
| **判分器**（grader） | 拿 verdict 与金标比，算 TPR/TNR/φ | **恒为机械比对 `pick == answer`，零模型，不是变量** |
| **判官**（judge，语义打分） | 开放式答案打分 | **已废弃**，不得用于本表 |

任何并列表**必须**写全四列：`verdict 产出者` / `作答提示词` / `材料来源（oracle 或检索）` / `判分方式（单断言或批量）`。
只写一个「judge」列，必然被误读成「判分器不同」。
