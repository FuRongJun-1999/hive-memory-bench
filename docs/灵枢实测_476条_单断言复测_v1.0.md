## 3. 措辞定生死：同一材料、同一模型，只换一句话

这是本轮最有价值的发现。**同一批 200 条、同一材料（top-3 整章）、同一模型（`deepseek-chat`）**，只换提问措辞：

| 提问措辞 | 认出真 | 认出假 | 平衡准确率 |
|---|---:|---:|---:|
| 「这条描述是否**完全符合原文**」（同尺口径）| 69.0% | 94.0% | **81.5%** |
| 「该陈述在材料下**是否为真**」（本仓旧措辞）| 94.0% | 59.0% | **76.5%** |
| 外部复测方照旧措辞重跑 | 90.0% | 65.0% | 77.5% |

**四个字「完全符合」，把模型的判定门槛抬高了：**

- 「符合原文」要求逐字核对 → 模型**更敢说「否」** → 认假 94%、认真只有 69%；
- 「是否为真」是语义判断 → 模型**更倾向说「是」** → 认真 94%、认假 59%。

**平衡准确率一平均，总分只差 5 点；但 TPR/TNR 结构反转 25 点。**
这不像「一个系统比另一个强」，更像**两种不同的判定策略**。

**推论（引用时必须带上）**：任何跨系统比较，**必须先对齐提问措辞**。否则「敢说否」的系统在真断言上会被低估，「敢说是」的系统在假断言上会被低估，而平衡准确率会把两者抹平。

## 4. 灵枢掉分掉在检索上，不在判断力

同一系统、同一条尺，552 条上灵枢 top-1 是 85.9%（贴锚 87.7%），476 条上只有 76.1%（低于锚 6.3 点）。差别在检索命中率：

| 系统 | 首章就是正解章 | 材料里含正解章 |
|---|---:|---:|
| memu（默认阈值）| 92.4% | 96.4% |
| memu（top-3）| 92.4% | 97.1% |
| **灵枢 top-1** | **64.5%** | — |
| **灵枢 top-3** | **64.5%** | **82.6%** |

按首章是否命中切开：

| 条件 | 首章命中组 | 首章未命中组 |
|---|---:|---:|
| 灵枢 top-1 | 81.1%（n=307）| **66.9%**（n=169）|
| 灵枢 top-3 | 82.1% | 81.7% |
| 锚 | 81.1% | 84.6% |

- **命中组 81.1%，与锚的 81.1% 一模一样**——材料本来就是同一章（307 条里 303 条答案相同，98.7%）；
- **未命中组掉到 66.9%**，差 14.2 点；
- **top-3 把这一课补上了**：未命中组也能到 81.7%。

所以 76.1% 与 81.9% 的 5.8 点差距（配对 18 比 46，p=0.0006）**全在「只给一章」这个决定上**，不在判断力。

### 4.1 为什么灵枢在 476 条上检索弱

476 条的事件槽是**概述**而非原句（基准自报逐字率 0.6%），检索器抓不准。

另有一个工程坑：476 条原文件的 `stmt` 用 **`·`（无空格）** 分隔，而 `pick_scopes` 的分词依赖空格：

| 格式 | top-1 | top-3 | 返回 0 章的条数 |
|---|---:|---:|---:|
| 原样（`·` 无空格）| 54.20% | 69.96% | **81** |
| 规范化（` · ` 有空格）| **64.50%** | **82.56%** | **3** |

**差 10.3 点，81 条直接检不到任何章。** 全部读数都用规范化后的 stmt。

## 5. 另一个坑：推理模型的空响应

首轮 40 条里 **32 条失败**，报 `模型返回空助手轮（content 与 tool_calls 双空）`。
token 明细：`completion_tokens: 75`，其中 **`reasoning_tokens: 73`** —— 73/75 烧在推理上。

**修法**：请求体固定带 `thinking: {"type": "disabled"}`。修后 200/200 全成功。
（与外部复测文档 §5.1 记的是同一个坑。）

## 8. 不适用条件

1. **全量 81.9% 由外部复测方测出**，本仓自测为 200 条抽样（其口径下复算 81.5%）；
2. **材料是整章拼接**（top-3 平均 6,024 字），不是灵枢生产模块返回的命中块；
3. **提问措辞影响 5 点总分、25 点结构**（§3），换措辞必须整表重测；
4. 单次运行，无重复测量；
5. 换作答模型会改 TPR/TNR 结构（±18 点），总分影响小。
