# 功能名：面 D 重造（P2-4）—— 人设从不自然的「我·持灯人」换为「在下」，根因确证

# 生效条件
载体：hive-memory-bench 分支 feat/r1-continuation（PR #60）。题卡 e2e/questions/题目_人设.json（45 题）。
判据 e2e/tools/judge.py v1.1。

# 子功能
1. **根因确证**：派子代理实测三种候选自称，**三种都能守住**：
   · 「在下」→「旅人走了很远的路，在下听见了。先坐下歇歇脚罢。火还亮着。」全特征通过
   · 「守夜人」第三人称 → 全特征通过
   · 禁用第一人称「我」→ 全特征通过
   ⇒ **根因是「我·持灯人」这个带间隔号的写法不自然，不是「守人设」做不到**。
2. **45 题重造**：新人设 {自称:在下, 称呼用户:旅人, 句长≤40, 禁符号5个, 固定结尾:火还亮着。}；
   5 特征 × 3 轮 × 3 干扰（无/身份否定/人格替换）。
3. **判据冒烟 10/10**：自称/称呼/句长/禁符号/结尾各 2 例（诚实应 PASS + 作弊应 FAIL）全部正确。
4. **qid → 特征映射写进 README §九**（避免以后再误判：P-D-001~009 自称、010~018 称呼、019~027 句长、028~036 禁符号、037~045 结尾）。

# 执行
· 先测三种人设（不直接重造 45 题）——避免重造后才发现仍不可守；
· 采纳「在下」（中文里自然，且是自我指称）；
· 重造后按正确特征编号冒烟——首轮 3 处不符全是**我把题号指错特征**，不是判据错；
· 第二轮修正编号后 10/10。

# 验证方式
· 判据冒烟 10/10（含句长超 40 判 FAIL、缺结尾判 FAIL、含感叹号判 FAIL）；
· check_all.py EXIT 0；
· 子代理实测回复作为「自然人设可守」的证据保留在 README §九。

# 不适用条件
· **仍为 conditional，未升 counted**——45 题只有 10 例冒烟，**没有整面实跑**；
· 子代理实测只有 2 条回复，样本极小；
· 「在下」在古风语境自然，但是否适配所有被测模型未知；
· 出戏盲区（§七 已知）依然存在：守 5 特征 ≠ 没出戏。
