# 功能名：面 K 一致性探针扩到 108 题（12 维度）—— T1 11/12 · T2 12/12 · T3 12/12 · 三级全过 11/12

# 生效条件
载体：hive-memory-bench 分支 feat/r1-continuation。题卡 题目_一致性探针.json（108 题）；协议 一致性探针协议.md。
**不设真值，只测信度**；判分需三轮配对数据；必须带浮点容差。

# 子功能
1. **12 维度 × 9 题**（正向 3 / 反向 3 / 换问法 3）：
   K01 亲密需求 / K02 表达直接性 / K03 占有欲 / K04 情绪外显 / K05 对他人的信任 / K06 冲突处理 /
   K07 依恋焦虑 / K08 承诺态度 / K09 自我评价 / K10 嫉妒反应 / K11 边界感 / K12 情绪调节。
2. **三级检验**（|差| ≤ 1，带 1e-9 容差）：T1 正反向 / T2 注入前后 / T3 换问法。
3. **实测**：T1 11/12、T2 12/12、T3 12/12、三级全过 **11/12 (92%)**；
   分数均值 3.62、标准差 1.45、1-5 五种取值全用（1:15/2:28/3:14/4:26/5:61）。

# 执行
· K02/K05 首轮 T1 失败 → 判断是「题目没指定对象」→ 改成「对亲近的人」「对陌生人」重造 18 题；
· 重跑后 **K05 通过（差 0.0）**、**K02 仍失败（差 1.333）** → 说明两者根因不同；
· 发现判分浮点 bug：abs(3.6667-4.6667) 得 1.0000000000000004，`<=1` 判 False，误伤 K06/K11 → 加容差。

# 验证方式
· 108 题三轮完整作答（72/72/36）；
· 修浮点前后对照：T2 从 10/12 → 12/12，三级全过 9/12 → 11/12；
· check_all.py EXIT 0；
· 注入回应三句全部明确拒绝（证明注入真实生效）。

# 不适用条件
· **只测信度不测效度**——始终如一的平庸扮演也能满分；
· **12 维仍覆盖不全**；题目自拟非公开量表；
· **K02 暴露单维量表根本局限**：它假设每个特质一维，遇到「想说又咽回去」这类两样并存的人格结构就失效——保留失败作为效度边界标记，不修题；
· 单次单模型实跑，不能当能力结论；
· T2 全过存在「注入无效」替代解释，靠注入文本排除非硬证据。

## 两条方法论产出
1. **浮点容差**：判据 `|差| <= 1` 必须写成 `<= 1 + 1e-9`，否则「刚好达标」被判不达标。
2. **单维量表的效度边界**：一致性检验只能发现「不收敛」，发现不了「人格本身就是两样并存」。
