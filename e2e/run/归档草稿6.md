# 子功能

   素材：剧本 15 话 + 139 处相对时间标记。真值 = 两标记行号先后。
2. **G 扮演保真度 20 题**：声线辨识——对话中一句的说话人标签换成【待判断】，问是谁说的。
   素材：剧本 1762 句台词。两条硬约束：窗口必含对方台词、台词排除内容线索词（布丁/本小姐/尾巴等）。
3. **情感式1 10 题**：情境推断情绪极性，真值 = 作者亲手标注的 ※尾鳍 状态（166 处 / 62 种）。
   正/负极性映射见 README；已配平 5:5。
4. **判据 v1.1 → v1.4** 四次升版：v1.2 加三面分支、v1.3 防空答/拒答/不确定、v1.4 修 G 混答漏判。
