# 端到端轨（真实史）· e2e/ v0.1

> 一句话：**作为端到端记忆评测的语料来源，替代 LoCoMo 在该位上的角色**。
> 不是构造题库，而是一位使用者与 AI 助手（DeepSeek）2026-07～09 的真实长期协作史：
> 16 份对话、**16,208,254 字符**、**8,146 轮**——协议设计、理论讨论、工程实践，
> 以及贯穿始终的真实「上下文超限 → 重新接入」续接史。

## 1 定位与理由

与构造题库（人工设计的信息挑战）的本质差别——三个词：

- **生态效度**：题目不是人出的，是"生活出"的——状态被反复确认、修订、跨会话恢复，全部真实发生；
- **天然人类基线**：材料里每一次真实的「上下文超限 → 重新接入」，都是使用者在**没有记忆系统**的条件下、**手工完成上下文重建**的现场记录。⇒ 记忆系统的对标物不是"别的系统"，而是**当时的人工复述本身**（评测问题可以精确到：记忆系统能否自动做到人类当时手工做的事——且无损、可核对、可回源？）；
- **答案键内生**：后续轮次即判据——"历史自己写下的答案"（后续某轮确认了某个状态，那它就是真值）。无需编题、无需人工写答案键。

## 3 四题型（同一材料、四种能力面）

| 型 | 内容 | 真值来源 | 对应能力 | 现状 |
|:--|:--|:--|:--|:--|
| **A 检索/召回** | 早期细节（谁起的名字、哪天说了什么、某个约定的原文）能否召回 ＋ **逐字可回源** | 原文逐字定位 | 记录层 | 待提取 |
| **B 状态演化** | 协议/项目状态的变更链：从什么改成什么、何时、依据 | 后续轮次的确认/修订句 | 断言账本＋双时间轴 | 待提取 |
| **C 续接预测** | 取真实断点 → 重建上下文 → 预测人类下一步 → 与真实下文对照 | **真实下文本身** | 预测性验证 | **首批发**（v0.1 候选 117 卡） |

## 4 C 型用法与判分（v0.1 草稿 · 待定稿）

### 用法（三步）

1. **材料终点**：把 `corpus/` 截至题卡所标断点的材料（或按被测系统"写入 → 检索"链得到的结果）交给被测系统；
2. **预测下一步**：要求它预测**人类在断点后的下一步**——他要接着做什么／说什么；
3. **与真实下文对照**：题卡内的「真实下文」（人类下一条 ＋ AI 当时的恢复开头）即答案键（内生）。

作答格式见 [`questions/作答契约_C型_v0.1.md`](questions/作答契约_C型_v0.1.md)。

### 判分三面读数（草稿）

| 面 | 读数 | 说明 |
|:--|:--|:--|
| **要素命中** | 预测覆盖真实下文关键要素的程度 | 真实下文＝答案键（内生） |
| **依据轴逐字回源** | 预测所引依据能否在 `corpus/` 中逐字定位 | 沿用既有线硬指标："可核对性" |
| **人类基线对照** | 对照"当时使用者手工复述能得到什么"（下界） | 系统应显著高于它，且可回源 |

> **v0.1 草稿 · 待定稿**——判分口径（题量、要素对齐粒度、人类基线的量化方式）以判分定稿为准（见 §6 roadmap）。

## 5 口径与政策

- **忠实原文**：材料为真实记录（非构造、非翻译）；除个别段落地移除（以 `*[内容已按公开口径移除]*` 标注）外，正文未做任何修改；
- **本机路径与署名**：材料正文含本机路径与作者署名（对话中的"阿符／荣"为授权署名的使用者本人）——**作者授权，忠实保留**（不做去路径化改写）；
- **旧密钥已脱敏**：历史文本中发现的两枚 API 密钥（**均非当前在役**）已脱敏为 `sk-***[已脱敏]***`；
- **训练污染提醒**：答案键（含"真实下文"）随本库公开 ⇒ 评测训练截止日在此之后的模型时，读数可能被污染，请自行评估；
- **私有层不发布**：2 份未录会话与全量原始导出另存私有层，不在本库发布。
