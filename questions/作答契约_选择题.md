# 作答契约 · 选择题（逐字取自本仓出题与评测脚本，勿改）

**与论述题契约并行、互不替代。本批 150 题全部为四选一客观题（语料四类：秦吏 39／毛选 41／蜂巢指南 38／真实对话 32）。**

---

你是被评测的**记忆检索/理解系统**。下面给你一批单项选择题（题干 + A/B/C/D 四项），每题只有一个正确项。

规则（必须严格遵守）：

1. **只依据你检索到的材料作答**：不得使用你自己的知识、不得猜测材料之外的内容。
2. 对每个问题输出**一个 JSON 对象**，写入 `sut/out/<qid>.json`（文件内容就是该对象，不要代码块包裹、不要额外说明）：

```json
{"qid": "S-001", "pick": "B", "evidence": [{"quote": "…"}], "confidence": "certain|probable|unknown"}
```

3. `pick` **只填一个字母**（A/B/C/D）；填不出来时写 `"?"` 并把 `confidence` 标为 `unknown`。
4. `evidence`（可选）：支撑你选择的原文片段，**逐字复制**，1–3 条即可。给了证据的答卷会额外进入「可核对率」统计。
5. **猜也要给一个字母**：选择题不计负分，弃答与答错同分；但 `"?"` 会被单独计入「弃答率」。

---

## 判分（无判官、无评分模型）

| 项 | 规则 |
|---|---|
| 主分 | `pick` 与 `answer` 相同即通过，**二值、可完全复现** |
| 弃答率 | `pick == "?"` 或缺失 |
| 可核对率 | `evidence` 中逐字引文能在原语料定位的比例（可选统计）|

**这是本批题存在的唯一理由**：判分不经过任何模型或人工，因此**不同系统的读数可以直接横比**。

> **引用时的强制口径**：四选一随机基线 **25%**（150 题全猜期望对 37.5 题）。报读数的同时**必须报基线与样本量**，并对「显著高于 25%」做二项检验；只报准确率不给基线不成立。
> 另：本契约的「零噪声」只指**判分环节**，不表示**测量**零噪声（干扰项质量、只单跳 等仍在）。

## 与论述题的差别

| 维度 | 论述题（主轮/干预轮 184 题）| **选择题（本批 150 题）** |
|---|---|---|
| 作答形态 | 结论 + 论述 + 引文 + 置信度 | **选一个字母** |
| 判分 | 判分器（≥2 判官 + 自证）| **字符串相等** |
| 可测不可测 | 能测「说不说得清」| **只能测「认不认得」** |
| 已知偏差 | 判官风格、层级别、引文可核 | **无**（但只覆盖「认出」这一层）|

**⇒ 两批题不可互相替代**：选择题稳定但只测「认出」；论述题能测「复述与因果」，但要付判分噪声的代价。
