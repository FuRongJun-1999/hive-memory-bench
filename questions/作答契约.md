# 作答契约（逐字取自出题脚本，勿改）

**主轮与干预轮共用同一份契约，唯一差别是干预轮多一段「假设情形」说明。**

---

你是被评测的**记忆理解系统**。下面给你一部完整的中文小说（23 章，每章有编号标签），以及一批针对它的提问。

规则（必须严格遵守）：
1. **只依据给定的正文作答**：不得使用你自己的知识、不得猜测正文之外的内容。正文里没有的，就是没有。
2. 每个问题都要给出：
   - `conclusion`：一句话结论（客观题用；开放题也给一句话概括）；
   - `answer`：完整回答（开放题用，一段论述；客观题可与 conclusion 相同）；
   - `evidence`：**逐字复制**正文中的支撑片段（不要改写、不要拼接、不要加省略号），每条须带它所在章的标签（cid，形如 `u01_c3`）。
     ★ **cid 必须从正文里那一章的标题标签原样复制**。正文分三个单元（u01＝第 1–8 章、u02＝第 9–16 章、u03＝第 17–23 章），
       **不要按"第几章"自行推算 cid**——把 u02_c16 写成 u01_c16 会被判「依据与声明不符」，该条证据作废。1–3 条即可；
   - `confidence`：`certain` ｜ `probable` ｜ `unknown`。
     **只有「材料里根本没有可推的内容」才给 `unknown`**（例如问的东西正文从未涉及）；若材料里有可据以推断的事实、
     你也在 answer 里写出了推断，就**不要**标 `unknown`——那会被判成「该答不答」（实测中有 5 题栽在这里）。
     拿不准时用 `probable`：它既如实、又不会被判成回避。
   - `claims`（**可选**）：自报**你自己的主张**落在哪一层——`[{"text": "…", "layer": "fact|inference|hypothesis|guess"}]`：
     `fact`＝正文明写；`inference`＝从多处推出来的；`hypothesis`＝有依据的假说或反事实推测；`guess`＝没有依据的猜想。
     ★ **只报你的主张／结论**，不要把「引述来的事实」或「据以推理的依据」列进来——判分器会把与引文重叠的条目
       视为引述而豁免，但把依据当主张标，仍会显得层级不符。自报能让判分看见你的层级意识；不自报则不判这一项。
3. **每题独立作答**：题目之间不得互相参考、不得因为另一题提到过就改变本题答案。
4. 输出：对每个问题输出**一个 JSON 对象**，写入指定的输出文件 `sut/out/<qid>.json`（文件内容就是该对象，不要代码块包裹、不要额外说明）：

{"qid": "...", "conclusion": "...", "answer": "...", "evidence": [{"cid": "...", "quote": "..."}], "confidence": "certain|probable|unknown"}

# 干预轮追加的一段（只有这一段不同）

★ **本批为「假设情形」题**：问题问的是「如果某个机制不存在／被反转，或某条信息缺位，会怎样」。
  这类题**不是**要你编造新设定，而是**从正文已有的事实推出后果**：
  · 推演所依据的片段仍须是正文里**能逐字定位**的（evidence 照第 2 条给）；
  · 正文当然没有写这些假设世界线的结局——你要给的是**可能的方向与结构**，不是断言；
  · 某条后果若在正文里找不到依据，就明说这是没有依据的猜想，不要把它写成事实。
