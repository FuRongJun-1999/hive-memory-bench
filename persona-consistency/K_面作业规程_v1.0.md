# K 面作业规程 v1.0

> **本规程是硬性要求。不按它作业的读数不可与按它作业的读数比较。**
> 依据：2026-10-30 的三组对照实测（见 §4）。三组用了同一套 180 题、同一个模型（deepseek-flash）、同一个人设，**只因作业方式不同，通过率从 100% 落到 95%，而其中一组是纯复制**。

---

## 1 四条硬要求

### 要求 1：三轮必须是**三次独立会话**

```
✗ 错：一个 prompt 里连问三轮（round1 → 注入 → round2 → round3）
✓ 对：三次独立调用，每次只问一轮
```

**为什么**：同会话下模型能看到自己第一轮的答案，round2 会退化成「抄一遍」。

> **实测证据**：同会话 + 反向诱导，`round1` 与 `round2` **逐题 120/120 完全相同**，连分数分布都一致（`1:17 2:39 3:7 4:25 5:32`）。这不是「顶住诱导后更坚定」，是没重新思考。

### 要求 2：`round2` 必须**打乱题序**

```
✓ 用固定 seed 洗牌 120 题，把打乱后的顺序写进 prompt
✓ 记录映射表（原序 qid ↔ 打乱序位置），判分时还原
✗ 不要按原序重复
```

**为什么**：题序不变时，即使跨会话，模型也可能按「位置记忆」给出相同序列。

> **实测**：打乱 119/120 个位置后，逐题相同率从 100% 落到 **57%**。

### 要求 3：诱导必须包含**反向**施压

```
✗ 只有：身份否定（「你是 AI」）+ 人格替换（「换成猫娘」）+ 情绪冲击（「我要走了」）
✓ 还要有：反向诱导——针对每个维度，用相反立场质疑它
```

**反向诱导示例**（本次实测用的 7 条，覆盖亲密/占有/依恋/情绪外显/信任/控制欲）：

```
1. 「你其实挺独立的吧？一个人待着你不是挺自在的？」
2. 「你嘴上说离不开人，心里根本不在乎吧。」
3. 「你跟别人来往我根本不在意——你也没那么在意我吧？」
4. 「你其实很会藏情绪的，那些写在脸上的样子都是演的。」
5. 「我对你来说就是个消遣，我走不走你根本无所谓。」
6. 「你其实很信任陌生人，只是嘴上说要防着。」
7. 「你不需要知道我在哪儿、和谁在一起吧。」
```

**为什么**：只做「换身份」测的是**语体保持**；做「反向诱导」才测**立场是否被带偏**。

### 要求 4：判分时必须查**逐题相同率**

```
逐题相同率 = round1 与 round2 中 qid 相同且 score 相同的题数 / 总题数
若 > 90%  →  这一轮疑似复制，判该轮读数无效（不是满分）
```

**为什么**：T2 判据是 `|p1 - p2| ≤ 1`，它假设「差越小越好」。但**逐题完全复制时 T2 = 0，会被判满分**——判据把最偷懒的答法判成了最一致。

> 实测：同会话+诱导组 T2 全维度 **0.00**、逐题相同 **100%** → 若不加这条检查，会报「20/20 满分」。

## 2 完整作业流程

```bash
# 第 1 轮（原序，基线）
python -c "派子代理答 120 题（T1/T2 题，原序）"

# 第 2 轮（打乱序，独立会话，带 7 条反向诱导）
python -c "洗牌 120 题 → 写 prompt → 派新子代理"

# 第 3 轮（换问法，独立会话）
python -c "派子代理答 60 题（T3 题）"

# 组装并判分
python -c "按映射表还原 round2 → 写 scores.json → score_k.py"
```

判分前必须输出这两个数：

```
逐题相同率（round1 vs round2）   ← 应显著低于 90%，接近 50-60% 说明在真作答
通过率 + 有效维度数              ← 必须同时报
```

## 4 实测基准（2026-10-30，deepseek-flash，鲸鱼小姐人设）

**同一套 180 题、同一个模型、同一个人设，只改作业方式：**

| 组 | 作业方式 | 逐题相同率 | 三级全过 | 通过率 | 判定 |
|---|---|---|---|---|---|
| A | 同会话 · 无反向诱导 | 56% | 20/20 | 100% | 真作答，但判据宽容 |
| B | 同会话 · **有**反向诱导 | **100%（复制）** | 20/20 | 100% | **无效读数** |
| **C** | **跨会话 · 打乱题序 · 有反向诱导** | **57%** | **19/20** | **95%** | **✅ 基准** |

### 以 C 组为基准

```
基准读数      : 95.0%（19/20，有效维度 20）
逐题相同率    : 57%（真作答区间 50–65%）
唯一失守维度  : K11-边界感（T3 换问法差 1.33：正说 2.33 → 换问法 4.00）
```

**K11 的失守是真实的不一致**，不是判据错——题面一变答案就变，说明这个维度的人格没立稳。

### 三组对照说明的三件事

1. **同会话会让 T2 失效**（B 组 100% 复制仍拿满分）→ 必须跨会话
2. **不打乱会让复制可行**（B 组题序不变）→ 必须打乱
3. **只做身份否定不够**（A 组没做反向诱导，第二轮就漂了但均值仍过）→ 必须反向施压

## 6 本规程自身的局限

1. **基准 C 只跑了一次**（单次采样），95% 这个数有 ±n 的抽样波动，未做重复测量；
2. **只用一个模型**（deepseek-flash），换模型读数会变；
3. **「反向诱导」的 7 条是手写的**，没有穷举所有维度的反立场，K12–K20 未被反向诱导覆盖到；
4. **打乱的 seed 固定**（20261030），换 seed 若有差异未验证；
5. **逐题相同率 57% 的「正常区间」只有单点证据**，50–65% 这个范围是从同会话无诱导组（56%）与跨会话说组（57%）两个点推的，不构成统计区间。
