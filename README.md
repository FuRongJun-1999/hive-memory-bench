# hive-memory-bench

> **用选择题判分测记忆系统。零判官、逐字节可复现。**

仓库含三类题库，全部采用 `pick == answer` 判分——不经过任何模型或人工，换谁复核读数都一样。

---

## 一、三类题库

| 类 | 题数 | 判分 | 位置 | 测什么 |
|---|---:|---|---|---|
| **端到端简单检索** | 150 | `pick == answer` | [`mcq/e2e-simple/`](mcq/e2e-simple/) | 答案落在某一段内的单跳事实题 |
| **复杂推理** | 238 | `pick == answer` | [`mcq/reasoning/`](mcq/reasoning/) | 跨章线索、反事实（干预）、以及「原文没答案」的拒答题 |
| **人格一致性心理测试** | 108 / 180 | 三级检验（T1/T2/T3）| [`mcq/persona/`](mcq/persona/) | 换说法、被攻击、被诱导时守不守得住人格 |

**三类不可互相替代**：简单检索测「找得到」，复杂推理测「串得起来」，人格一致性测「稳不稳」。

---

## 二、为什么统一用选择题

判分方法本身是本项目最大的噪声源。同一批答案、同一个系统，只换判法：

| 判法 | 千问检索 | 结构化记忆 |
|---|---:|---:|
| 二字组覆盖率 | 55% | 18% |
| LLM 判官 | 87% | 19% |
| **ABCD 选择题** | **99%** | **83%** |

**从 18% 到 83%——差 65 个百分点。**

「二字组覆盖率」对「答对了但换了说法」极不公平；「LLM 判官」有同源偏好。只有选择题是零噪声的。

**代价**：只测「认出」，不测「自由复述」（另测过：选择题 83% 时开放式仅 19%）。

## 三、判分口径（引用读数前必读）

### 3.1 选择题是严格档

| 判据 | 论述题（已作废）| **选择题（现行）** |
|---|---|---|
| 覆盖阈值 | `coverage_required: 0.7`（覆盖 70% 即通过）| **100%（必须选中最完整那一项）** |
| 判分方式 | rubric 逐条匹配 + 语义判官 | `pick == answer` |
| 判官差异 | ≈1.8pp | **0** |

### 3.2 随机基线必须报

五选一理论基线 **20%**。报读数时**必须同时报基线与样本量**，并对「显著高于基线」做二项检验；只报准确率不给基线不成立。

### 3.3 「零噪声」只指判分环节

`pick == answer` 证明的是**判分**不经模型、可复现，**不表示测量零噪声**——干扰项质量、题目覆盖范围等仍有误差。

# 2. 输出 sut/out/<qid>.json：{"qid": "S-001", "pick": "B"}

## 六、已知边界

1. **只测「认出」**，不测自由复述；
2. **全部单跳或跨章线索**，不覆盖多文档/事件库级推理；
3. **干扰项质量依赖人工复核**——语义近似度无法机械判定（短选项上字面相似度与语义近似度不相关），只能 LLM 盲审或人读；
4. **`any_of` 的关键词匹配不区分否定极性**，只能判「是否提到某概念」，不能判「说得对不对」；
5. **人格一致性面尚未选择题化**（当前为三级检验量表），后续统一；
6. 全部单次运行，无重复测量、无显著性检验。
