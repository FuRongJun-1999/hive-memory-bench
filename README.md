# hive-memory-bench · 记忆系统评测

各种记忆系统，到底能记住什么，又会忘掉什么？这个项目把长文本里的事实、线索和因果整理成可检查的题目，用同一套规则比较不同系统。

目前覆盖三类：**简单检索**（150 题）、**复杂推理**（476 条 + 92 题）、**人格一致性**（108 / 180 题）。


## 五分钟跑起来

只需 Python 3.10 或更新版本，无第三方依赖、无 API key，也不会产生模型费用。

```sh
git clone https://github.com/FuRongJun-1999/hive-memory-bench.git
cd hive-memory-bench

# 1. 系统读题（只给 stmt / question + options，不给 answer）
#    输出 sut/out/<qid>.json

# 2. 把 sut/out/*.json 汇总成 JSONL（每行 {"qid": "...", "pick": "B"}）

# 3. 判分
python grade_mcq.py --questions mcq/reasoning/题目_六元素判断题_476.json --answers answers.jsonl
```

## 自己复测

三个纯标准库脚本，不需要装灵枢、不需要 API key：

```sh
# 检索层（确定性，秒级）
HMB=$(pwd) python scripts/bench_state_track.py

# 端到端：生成 552 条单断言任务 → 你用自己的系统作答 → 判分
python scripts/reproduce_e2e.py --task --arm top1 --out tasks.jsonl
python scripts/reproduce_e2e.py --grade --picks my_answers.jsonl
```

灵枢检索需要内部库，外部跑不了，所以仓库发布了**检索明细**（[`readings/lingshu_retrieval_rubric92.json`](readings/lingshu_retrieval_rubric92.json)：552 条断言各自的 gold / top-1 / top-3 章号）。据此取原文即可复测，不必复现检索。详见 [scripts/README.md](scripts/README.md)。

## 我们怎么理解“记住了”

先说清怎么算记住。历史交给系统自己的记忆流程处理，考试时从独立会话提问——**不能把完整材料直接塞给作答模型冒充记忆测试**。

成绩写「通过几条 / 实际考几条」。只判事实、主体、地点、时间和边界，不判说话风格。忘了、记错了、没有依据却编了，分别记录。

**判分器永远是机械比对**：判断题看 `是/否`，选择题看 `pick == answer`，不经过任何模型或人工。作答的人（或模型）可以是任何系统，判分这一层换谁复核都一样。

**只看开卷会骗人。** 我们做过一批五选一，开卷 100%，但**不给材料也能答对 82.8%**——那不是记得，是选项本身泄漏答案。所以任何题库入库前都要跑一遍闭卷，只有「闭卷接近随机」的题才算测到了记忆。这条是硬门槛，详见[验证报告](docs/多跳六元素rubric92_验证报告_v1.0.md)。

## 数据来源

语料三类：《蜂巢世界漫游指南》（6 万字，23 章，在本仓）、真实对话史（16 个文件，约 1,368 万字符，在本仓）、以及《秦吏》与《毛选》摘录（**他人作品，不公开原文**）。

简单检索题的 150 题里，**70 题可回原文核对**（蜂巢 38 + 对话 32），另 80 题因版权第三方无法复算。
