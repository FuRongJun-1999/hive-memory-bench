# hive-memory-bench · 蜂巢记忆基准 v1.0

**一个以长文本世界模型为载体的中文 LLM 基准：测量「跨章节因果记忆 ＋ 证据保持 ＋ 干预后因果边界维护」。**
以一部 23 章、6.1 万字的小说为材料，出 **184 道因果理解题**（主轮 92 ＋ 干预轮 92），
配有**可运行的判分器**与**六家前沿模型的外测数据**。

> 它测的不是"能不能检索到那句话"，而是三件分层的事：**能不能把散在各章的东西串成因果链（Layer A）、
> 能不能在信息被抽掉一块时划出因果边界——什么跟着倒、什么照旧（Layer B）、
> 以及每个判断能不能回源核对（Layer C）**。三层不可互相代理，分层定义与全部读数索引见
> [`docs/基准定位与三层结构_v1.0.md`](docs/基准定位与三层结构_v1.0.md)。

> 只在与它共有的 146 题上可比（那张表见 [`results/成绩总表.md`](results/成绩总表.md) §1.2）。
> 它的读数偏低另有两个与能力无关的原因：**10 题作答错位**（`q011–q020` 的答卷填的是同号开放题的答案）、
> 干预轮答案中位只有 79 字（其余各家 162–487）。

**三条从数据里读出来的**（详见 [`docs/基线分析_v1.0.md`](docs/基线分析_v1.0.md)）：

- **无记忆系统的实际成绩是 37%–49.5%**，与参考实现差 17–29 个百分点。
- **20.7% 的题四家外测全部够不到 0.7 的线**，而只有 13.6% 的题大家都过。
  参考实现在这 38 道"无人过"的题上答出 12 道——**这 12 道就是记忆系统当前可量化的增益空间**。
- **抽掉一块信息，成绩普遍掉约 10 个百分点**；而各家答卷的失败模式高度一致：
  能说出"缺了什么"，说不出"缺了之后**哪一层照旧、哪一层失去依据**"。
  （这条已被正式化为一个指标——**因果边界保持率**，含"过度传播／干预失明"两类错误分类，见
  [`docs/因果边界保持_v1.0.md`](docs/因果边界保持_v1.0.md)。）
  （DeepSeek V4.1 Flash 是唯一例外：干预轮 47 反超主轮 43，长于反事实推理。）
- **在六家共同题集上，GLM 5.3 Flash 与 DeepSeek V4.1 Flash 几乎打平（71 vs 70），形状却相反**：
  前者靠主轮（30/23），后者靠干预轮（23/**47**）——**总分抹平结构，两栏必须分开看**。

## 记忆系统实测（v1.4 新增）

上面那 184 题测的是**模型**。另有一组实验测**记忆系统**：把六家记忆系统（OpenViking／灵枢／朴素 BM25／
Mem0／MemOS／Hindsight）接到**同一台生成器**上、用同一批因果推理题考，
**唯一变量是它检索出来的上下文**。三层读数（逐字率／地基保留／因果证据链）都做了双切点复现：

| 梯队 | 系统 | 关键读数 |
|:--|:--|:--|
| **可用** | OpenViking | 逐字 100%，证据链 99–100% 可核实，**地基触达反超直读** |
| **可用** | 灵枢 v0.7.1 | 证据链 98–99%、地基触达 5–7/19（**切 A 反超 OpenViking**）；写入仅 0.01–0.02 秒（旧版此两项为 86–99%／3–4/19，**本版已大幅改善**） |
| 可用（有损耗） | BM25 | 证据链 100%，但地基触达掉到 3–5/19（选段靠表面相似度） |
| **不可用（架构性）** | Mem0／MemOS／Hindsight | **引文逐字可定位仅 0–2%**——抽取式改写让因果推理的证据轴整条塌掉；**2026-10-03 零材料对照进一步判定：因果推理本身来自模型，它们既给不了推理、也交不出依据（见下下节）** |

> **一句话**：决定性差异不在「检索得准不准」，而在「交出来的东西能不能当证据」；
> 且**写入成本跨 4 个数量级，与效果无关**（灵枢 0.01–0.02 秒与 165 秒的 OpenViking 在保地基上同级）。
> **灵枢数据为 v0.7.1 版（2026-10-04 重跑更新**，旧版读数见 `docs/记忆系统对比_v1.0.md` 各表下注）。
> 全文与全部读数：[`docs/记忆系统对比_v1.0.md`](docs/记忆系统对比_v1.0.md)、
> [`systems/readings.json`](systems/readings.json)；同一套诊断可用
> [`systems/三轴诊断.py`](systems/三轴诊断.py) 跑在**你自己的语料**上。

### 压缩的代价就是因果丢失（2026-10-02 新增）

上一条测的是「**交出来的东西能不能当证据**」；这一条回答一个更具体的问题：
**为什么压缩式记忆系统得到的摘要，无法完整推理因果关系？**

答案不是"压缩率太高、信息不够"的直觉版，而是一个**方向性偏差**：
抽样按"与提问的相似度"选段，而**矛盾的另一侧恰恰与提问词面不重叠**
（提问说「反对权威」，另一侧写的是「唯有强大的王者…才是自由的前提」）
⇒ 压缩**系统性地丢掉的是"对面那一块"**，不是随机信息。

| 读数（9 条人工裁定的结构性矛盾题 × 同一生成器） | 朴素 BM25 | OpenViking | 灵枢 v0.7.1 | Mem0 | MemOS | Hindsight |
|:--|--:|--:|--:|--:|--:|--:|
| **覆盖**：矛盾那一块还在检索片段里吗（逐字） | **9/9** | 5/9 | **2/9**（↓旧版 5/9） | **0/9** | **0/9** | 1/9 |
| **指出**：检索片段当唯一上下文时答得出来吗 | **6/9** | 5/9 | **2/9**（↓旧版 5/9） | 4/9 | 2/9 | 1/9 |
| **依据轴**：答卷引文能在原文逐字定位吗 | 100% | 100% | **86.0%**（↓旧版 100%） | 5.6% | 1.4% | 5.7% |

三条单调律：**①单句能保住、"跨章对立对"保不住**（需两处不同章记载同时进同一个 k=10 时，
除 BM25 外全军覆没）；**②压缩越狠丢得越彻底**（Hindsight 1/9 ＜ MemOS 2/9 ＜ Mem0 3/9 ＜ OpenViking 5/9 ＜ BM25 9/9）；
**③覆盖与指出逐格对齐**——没带回那一块的系统就是答不好的那一家（且携带全部块的无筛选 BM25 **反超了直读全书**，
说明问题不在生成器推理，在上下文里"那一块"在不在）。
**灵枢 v0.7.1 在此实验下降（5/9→2/9）**：该版逐字与保地基全面变好、但检索更聚焦——
"另一侧"与题面词面不重叠，越聚焦越不易带回，**恰是本文机制的又一次复现**（详见
[`docs/压缩的代价就是因果丢失_v1.0.md`](docs/压缩的代价就是因果丢失_v1.0.md) 版本注）。

> 全文（含因果链与使用建议）：[`docs/压缩的代价就是因果丢失_v1.0.md`](docs/压缩的代价就是因果丢失_v1.0.md)；
> 可跑在你自己的语料上：[`systems/压缩代价.py`](systems/压缩代价.py)
> （准备材料＋你的检索结果＋一份"矛盾对清单"，它会报"两侧存活／只剩一侧"与依据轴定位率）。

### 零材料对照：因果推理是模型给的，依据才是记忆的（2026-10-03 新增）

前两条测的都是"接入材料后拿到了什么"；这一条反过来问一个归因问题：
**把这些因果题拿给同一台生成器、什么都不检索，会得多少分？**

| 系统 | 因果栏（采分点命中率） | 相对零材料 | 符号检验 |
|:--|--:|--:|:--|
| **零材料对照** | **67.9%** | — | — |
| 朴素 BM25 | 62.5% | −5.4pp | p=0.21（打平） |
| Mem0 | 60.2% | −7.7pp | p=0.029 |
| OpenViking | 59.0% | −9.0pp | p=0.011 |
| 灵枢 | 58.0% | −9.9pp | p=0.029 |
| MemOS | 56.9% | −11.0pp | p=0.018 |
| Hindsight | 50.3% | −17.6pp | p<0.001 |

**在当前语料、题集、生成器与检索设置下，零材料 67.9% 高于全部六家接入材料后的读数**——因果推理这一步是模型给的，
不是记忆系统给的（材料净贡献 −5.4 到 −17.6pp）；这也解释了为什么该维度各家被压平（极差仅 12pp，而"逐字依据"
维度极差 68pp）。三条混杂检查（闭卷臂内部长度×得分 r=−0.28／判官盲判／一致性检查）、
"卷面零题面外专名"的机械核对、以及**结论的适用范围与复现需求（多生成器／多语料／多 k）**都在全文里。

⇒ **选型落点**：要「能核对的因果依据」，用 OpenViking／灵枢（原文路线）＋ BM25 基线；
**Mem0／MemOS／Hindsight 判不可用（架构性）**——既提供不了推理（那是模型的），
也交不出依据（逐字/可回源结构性 0%），且不是调参能修的（另一半论证见上一节"压缩的代价"）。

> 全文：[`docs/零材料对照_因果归因_v1.0.md`](docs/零材料对照_因果归因_v1.0.md)；
> 聚合读数：[`systems/readings.json`](systems/readings.json) `零材料对照` 段。

## 判分可靠性与题目独立性（v1.4 增补）

两份**方法论披露**——把本基准自己的弱点先量出来：

- [`docs/判分可靠性_v1.0.md`](docs/判分可靠性_v1.0.md)：**为什么不用单一判官**。
  三次实测里两次语义判官一致率完全不可用，唯一一次"看起来可用"的一致是**尺度塌缩**造出来的假象。
  现走四道防线：机械先决 / ≥2 判官同材料同判据盲混 / **固定锚且锚必须先自证**
  （锚上正确率 − 多数类基线 **≥ 15 个百分点**，任一判官不合格整批作废）/ 一致率不达标就判「不可测」。
  报告如实记录两次真实翻车（判官用退化策略、以及**锚垫底其实是答案键的问题**）。
- [`docs/题目独立性_v1.0.md`](docs/题目独立性_v1.0.md)：**92 题不等于 92 个独立样本**。
  答案键的 `cid` 依赖面可算出：**23 个章节点被引 338 次、前 10 个占 64%**；单章最高被 **30/92 题**依赖；
  **5 对题依赖面完全相同**（可证明不独立）、426 对存在真包含；**前 20 题就触及全部 23 个章节点，
  后 20 题新增 0 个**。⇒ **报区间请按「有效样本量 ≤ 24」折算，别按 92 折算。**
  复跑：`python -X utf8 独立性分析.py`（读数 [`results/独立性读数.json`](results/独立性读数.json)）。

## 怎么用

**① 只看成绩** → 读 [`results/成绩总表.md`](results/成绩总表.md) 与 `results/boards/*.json`
（后者是逐题判定：`{"qid": "q001", "verdict": "pass|fail"}`）。

**② 测你自己的系统**：
把 `questions/` 与 `corpus/`（或直接用 `questions/答题器.html`，离线可用）交给被测方，
按 [`questions/作答契约.md`](questions/作答契约.md) 产出 `sut/out/<qid>.json`，然后：

```bash
python -X utf8 导入回收作答.py 作答.json          # 拆成 sut/out/<qid>.json ＋ 体检
python -X utf8 score_sut.py build                 # 规则层
python -X utf8 semantic.py prepare real --select semantic   # 生成语义层判官请求
#   让判官读 semantic/req/real/*.md、把 JSON 写到 semantic/out/real/<同名>.json
python -X utf8 semantic.py finalize real          # 机械校验 span → 终裁
python -X utf8 score_sut.py report                # 计分板
python -X utf8 三分数.py real --label "我的系统"   # B 覆盖 / C 引文保真 / 字数
```

**③ 复现判分**：`python -X utf8 check_all.py check` 应输出 `0 错误`；
`results/boards/` 里每次判定的 `qid → verdict` 可按同样流程逐题核对。

## 两条必读声明

**一、干预轮的答案键未公开（有意为之）。**
`cards/` 只有主轮 92 题的答案键；干预轮 92 题**只公开题面与分数**，不公开采分点。
这样干预轮仍可用于评测**尚未见过本题**的系统。如果你的研究需要完整答案键，请联系作者。
同理，`docs/记忆系统对比_v1.0.md` 用到的那 20 题及其地基句清单也属**未公开题集**，只报读数、不报题面与答案键。
`docs/压缩的代价就是因果丢失_v1.0.md` 用到的 9 条结构性矛盾题（题面、答案键、以及每条"矛盾赖以成立的那一块"
的位置）同属**未公开题集**——该文只报聚合读数与口径。

**二、训练污染提醒。**
本基准及其答案键（主轮部分）自公开之日起即成为公开数据。**用它评测训练截止日在此之后的模型时，
读数可能被污染**，请自行评估。作者保留一套未公开的留出材料用于后续评测。
