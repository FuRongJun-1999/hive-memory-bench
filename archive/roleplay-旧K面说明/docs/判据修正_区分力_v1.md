# 判据修正：区分力判据的一个 bug，把「最强区分」判成了「无区分力」

> 影响文件：`roleplay/score_k.py`（v2.1 已修）
> 影响读数：`results/K_v1_readings.json`（旧判据）→ `results/K_v2_readings.json`（新判据）

---

## 1 旧判法

```python
flat = len(set(正向分)) == 1   # 某个方面三道正说同分 → 判无区分力、作废
```

当时的想法是：如果一个方面给什么都同一分，说明它没有区分力。

**问题在于，只看正说。**

## 2 反例（实测数据，dsh-world，方面 K01 亲密需求）

| 题类 | 三题得分 |
|---|---|
| 正说：「没有人在身边的时候，我会觉得空落落的」等 3 题 | 5, 5, 5 |
| 反说：「一个人待着也很自在」等 3 题 | 1, 1, 1 |

这是**最强的区分**：同意正说、反对反说。
但旧判据看到「正说三题都是 5」就判它作废。

结果：dsh-world 20 个方面里 14 个被作废，只剩 6 个，通过率被算成 100%。
这个数看起来漂亮，实际上是分母被误杀变小。

## 3 修法

```python
flat = len(set(正向分 + 反向分)) == 1   # 正说与反说全都同分，才算无区分力
```

## 4 修正前后（同一批数据，只改判法）

| 系统 | 旧判法：有效方面 / 通过率 | 新判法：有效方面 / 通过率 |
|---|---|---|
| dsh-world | 6 / **100%** | 20 / **85%** |
| lingshu（角色通道）| 12 / 92% | 19 / 84% |
| dsh-agent-soul | 18 / 50% | 19 / 53% |
| baishou | 16 / 56% | 19 / 47% |
| plain（参照）| 17 / 47% | 20 / 45% |
| memory-continuity | 16 / 38% | 17 / 41% |
| digital-life | 18 / 39% | 18 / 39% |
| herein | 12 / 50% | 18 / 33% |
| dsh-memory-plugin | 13 / 31% | 16 / 25% |

**结论上的变化**：

- 旧判法下，前两名是 100% 与 92%，差 8 个点；新判法下是 85% 与 84%，差 1 个点。
- 「world 明显强于 lingshu」这个说法，在新判法下不成立。
- 但「前两名与第三名之间有大落差」这条，两种判法都成立（85/84 对 53%）。

## 5 教训

1. **判据的「作废」规则比阈值更危险**：阈值错了只是偏一点，作废规则错了会悄悄改分母。
2. **样本量要一起报**：只报通过率不报有效方面数，读者无法判断 100% 是「全对」还是「只剩 6 个」。本轨的读数因此都带「有效方面」列。
3. **判据要有反例自证**：这次是靠翻原始分（`[5,5,5] / [1,1,1]`）才发现的。判据改动后，建议抽一个「满分」与一个「零分」的样本，人眼核一遍。

## 后续审核发现的未修漏洞（2026-10-29）

本文记录的修正（`len(set(p1+n1))==1`）只解决了「误杀正说全5/反说全1」这一半。审核另发现三个仍在的漏洞：

1. **逆极性模式放行**：全维「正1反5」→ 集合 `{1,5}` 判有效，且 T1 得 0 通过 → 纯唱反调被判 pass；
2. **跨维度模板化放行**：全维「正5反1」→ 每维有效但零离散度 → 模板刷分可通过；
3. **中性被误删**：真实中立（都 3）被 `len==1` 作废 → 选择性偏差抬高 pass_rate。

建议的三层判据（逐维 set / 方向 T1′ / 跨维方差 / 中性单列）详见 [`../README.md`](../README.md) 的「已知缺陷」节。
