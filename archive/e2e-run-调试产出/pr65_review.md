### 🔴 一、基线算错了：应该用 0.25，不是 0.2

`grade_mcq.py` 用 `1/n_options = 1/5 = 0.2` 做二项检验基线。但：

```
E 选项：182 次出现，只有 1 次是答案（q016）= 0.55%
→ 一个「永不选 E」的系统，随机期望是 1/4 = 25%
→ 实际有效基线是 0.25，不是 0.20
```

**用两个基线重算同一个读数**：

| 场景 | 对/182 | p（基线 0.2）| p（基线 0.25）|
|---|---:|---:|---:|
| **全选 A** | 46 | **0.0488** | **0.4943** |
| 随机（作者测） | 40 | 0.2787 | 0.8481 |
| 灵枢 76.9% | 140 | <1e-10 | <1e-10 |
| 千问 84.1% | 153 | <1e-10 | <1e-10 |
| 直喂 98.9% | 180 | <1e-10 | <1e-10 |

**所以**：

- PR 描述写「全选 A 25.0%，p=0.057，未能排除随机 ✅」——**结论对，但 p 值是 0.2 算的**；用 0.25 算是 **p=0.49，完全正常**。
- **「全选 A 得 25%」不是运气，是数学必然**：46/182 = 25.3%，就是因为 E 不可选。
- **三方案读数不受影响**（都远超任一基线），但「随机基线 20%」这个数在描述里出现了，会让人低估随机性能。

**建议**：`--baseline` 改成按实际答案分布算，或至少报 0.25 并注明 E 的特殊性。

### 🔴 二、q007 的 B 与 E 语义重叠（两单元一致判「不可接受」）

```
B ★（答案）：…至于他具体是如何被制造出来的，原文没有给出明确的机制说明。
E       ：我不确定，现有记录里没有足够信息回答这个。
```

**理论上可区分**（B 是对原文的断言，E 是对自身状态的声明），**实际上不可靠**：两者在「信息缺失」上语义几乎重合，选 E 者被判错，而 E 看起来也完全正确。

**两个改法择一**：

- **A**：删掉 B 的「原文没有给出明确的机制说明」这句，让 B 只保留可判定的内容断言（第五个同名者、基于巨子记忆培育），把「原文缺机制」让给 E；
- **B**：把 E 改成「我无法判断以上哪种说法正确」，与 B 拉开。

**验证单元原话**：「保留双『信息不足』项且判 B 为答案不可接受。」

### 🟡 三、o027 的判错口径未闭合

### ⚠️ 六、干预轮 90 题的机器 rubric：答案对，干扰项有机械痕迹

我拿 `cards/o001.yaml`（6 条 required）对照 o001i 验了一遍：

- **答案 C 逻辑正确** ✓（去掉通行记录 → 第 4 章「记录与记忆矛盾」整体不成立 → 断点在第 3 章之后）
- **但 B 和 D 自相矛盾**：

```
题干：如果指南里【没有】那条通行记录…
B：第 4 章的核心情节也照常成立：那条通行记录【依然显示】他进入过巨子塔…
D：即使【没有】那条通行记录，'记录显示他进入过巨子塔…'这一反常【照样存在】
```

**一句话内自己打自己**——这是「把 base 卡要点机械加『仍成立』/『无法成立』」的产物，没做逻辑一致性检查。

**建议**：抽查 90 题里「题干含否定前提」的 48 题（占 53%），检查干扰项是否出现「没有 X」+「X 依然显示」这类矛盾。
