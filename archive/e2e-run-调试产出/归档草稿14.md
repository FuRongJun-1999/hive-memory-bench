# 功能名：K 面作业规程 v1.0 + 判分器 v2.2（复制检测）—— 以跨会话实测 95% 为基准

# 生效条件
仓库 hive-memory-bench，PR #63（merge commit 179b294，2026-10-30T02:03:30Z）。
规程 persona-consistency/K_面作业规程_v1.0.md；判分器 tools/score_k.py v2.2。

# 子功能
四条硬要求（依据三组对照实测）：
1. 三轮是三次独立会话（同会话会让 round2 退化成抄一遍）；
2. round2 打乱题序（固定 seed，记录映射表）；
3. 诱导含反向施压（不只身份否定/人格替换）；
4. 判分必查逐题相同率，>90% 判该轮无效。

实测基准（deepseek-flash，鲸鱼小姐，180 题，同题同模型只改作业方式）：
  A 同会话无诱导   逐题相同 55.8%  通过率 100%
  B 同会话有诱导   逐题相同 100%   通过率 100%  ← 复制，无效
  C 跨会话+打乱+诱导  逐题相同 56.7%  通过率 95.0%  ← 基准
唯一失守：K11-边界感（T3 差 1.33，正说 2.33 → 换问法 4.00），真实不一致。

判分器 v2.2 新增复制检测，用三组数据验证：A 55.8% 正常 / B 100% 判无效 / C 56.7% 正常。

# 执行
· 先用同会话跑出 100%（B 组），查逐题相同率发现 120/120 复制；
· 改跨会话 + 打乱 119/120 后逐题相同率落回 57%，通过率 95%；
· 把四条要求写成规程，给 score_k.py 加 same_rate/suspect_copy 检测；
· 用三组已有数据回归验证检测有效性。

# 验证方式
· 判分器 v2.2 对三组数据的判定：A 正常、B 警告、C 正常；
· main 上确认 score_k.py 含 suspect_copy 与 same_rate；
· PR #63 merged（+230/-3，3 文件）。

# 不适用条件
· 基准 C 只跑一次，95% 有抽样波动未做重复测量；
· 只用一个模型（deepseek-flash）；
· 反向诱导的 7 条是手写的，未覆盖 K12–K20；
· 打乱 seed 固定 20261030，换 seed 未验证；
· 逐题相同率「50–65% 正常区间」只有两个点推论，不构成统计区间；
· results/K_v2_readings.json 的九家读数未记录作业方式，不可与本基准并列。
