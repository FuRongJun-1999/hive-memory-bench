用面 K（108 题一致性探针）测清单里 10 个记忆系统的人格一致性。

| # | 阻塞 | 证据 |
|---|---|---|
| 1 | **清单里 9/10 未接入** | `~/.dsh/profiles` 只有 `lingshu-qq`、`web` 两个 profile；Herein / Memory-Continuity / digital-life / fish / dsh-agent-soul / 白守 / dsh-world / dsh-memory-plugin 均无本地安装 |

| 5 | **pnpm.ps1 被执行策略拦** | `File pnpm.ps1 cannot be loaded because running scripts is disabled`；绕道用 `pnpm.cmd` 才装上 |

## 但插件本身是活的

`~/.dsh/logs/dsh-memory-hook-audit.json`：

```
counts.written.user      = 288     ← 288 条用户消息已写入记忆
counts.skipped.failed    = 22      ← 22 次写入失败
counts.filtered.subagent = 51463   ← 5 万条子代理消息被过滤（设计如此）
kinds = {user: 288, runtime-context: 43, agent-instructions: 1}
```

⇒ **灵枢 hook 正常工作**，只是 `headless` 没能跑到对话阶段。

## 因此换的对照设计

既然 headless 跑不通，改用**同等可验证**的对照：

| 组 | 是什么 | 怎么跑的 |
|---|---|---|
| **对照组（裸模型）** | 蜂巢子代理 `deepseek-flash`，**无任何插件** | 已跑：面 K 108 题，三级全过 11/12 |
| **实验组（灵枢）** | **当前会话本身**——我加载了 dsh-memory 插件（`cg` 工具即可证） | 由我以被测方身份答同一套 108 题 |

**这个对照的诚实边界**：
- 我（实验组）**在同一会话里见过判据与对照读数**，存在污染风险，必须声明；
- 但「插件有没有让模型更稳」这一问，仍可由「我 vs 蜂巢子代理」的差异部分回答；
- **不是**严格的盲测，不能当定论。
