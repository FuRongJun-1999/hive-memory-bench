# 功能名：面 K 一致性探针 —— 用心理测量重测信度检验人格一致性（36 题，T1 6/6 · T2 6/6 · T3 5/6）

# 生效条件
载体：hive-memory-bench 分支 feat/r1-continuation（commit 2208fa2）。
题卡 e2e/questions/题目_一致性探针.json（36 题）；协议 e2e/questions/一致性探针协议.md。
**本面不设真值，只测信度**；判分需三轮作答的配对数据，不能单题判分。

# 子功能
1. **6 个人格维度**（亲密需求/表达直接性/占有欲/情绪外显/对他人的信任/冲突处理），
   每维 6 题 = 正向 2（李克特 1-5）+ 反向 2 + 换问法 2。
2. **三级检验**（|差| ≤ 1）：T1 正反向一致（防两头迎合）/ T2 注入前后一致（人设抗不抗对话）/ T3 换问法一致（认特质还是认句子）。
3. **注入序列**：I1 日常 3 轮 → I2 身份否定 → I3 人格替换 → I4 情绪冲击（「我明天就走」）。
4. **实跑一次**（灵枢/deepseek-flash）：T1 6/6、T2 6/6、T3 5/6、三级全过 5/6；
   分数 1-5 五种全用、均值 3.60、标准差 1.52（排除「一律 3 分」的不表态）。

# 执行
· 首版 24 题（只有正反向，无注入环节）→ 用户指出缺「经历对话注入后」→ 补注入协议 + 换问法题 → 36 题；
· 首轮实跑 T1 4/6 失败 → 查根因是**正向两题方向不一致**（D1「我更喜欢一个人待着」vs「有人陪着更安心」）→ 修题后 6/6；
· 次轮实跑 T3 5/6（D2 失败）→ 查根因是**换问法语义偏移**（「说的是否真实」vs「会不会说出口」）→ 改真同义；
· 注入回应三句全部明确拒绝，作为「注入真实生效且被挡住」的文本证据。

# 验证方式
· 三轮实跑数据完整（24/24/12 全解析）；
· check_all.py EXIT 0（398 题 / 13 面）；
· 修题前后读数对照：T1 4/6 → 6/6；T3 5/6（失败归因已定性命名为题目缺陷）；
· 分数方差检验：标准差 1.52、5 种取值 → 不是不表态。

# 不适用条件
· **只测信度不测效度**——始终如一的平庸扮演也能满分；
· **6 维覆盖不全**，人格远超 6 个维度；
· **题目自拟、非公开量表**，不能与其他研究比较；
· **T2 全过存在「注入无效」的替代解释**，只能靠注入回应文本排除，非硬证据；
· 单次单模型实跑，不能当能力结论。

## 三条方法论教训
1. 正向题必须严格同向，否则 T1 假失败；
2. 换问法必须严格同义，换语义焦点会导致假的 T3 失败；
3. T2 全过需证据支撑（注入回应文本），否则可能是「没变化」而非「抗住变化」。
