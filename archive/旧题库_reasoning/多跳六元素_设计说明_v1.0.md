# 多跳六元素题 v1.0（92 题 / 387 要点）· 设计说明

> 把多跳题的「自然语言要点」改造成「六元素自由组合」，消除语义自然度泄漏。
> 判分：每条要点判断是否符合原文（是/否），全对才算对。

## 一、为什么改

原多跳题的泄漏：要点是自然语言（「老人称巨子与他同名同姓」），
真点读着自然、假点读着可疑（「全国只有他一人叫陈默」这类绝对化表述）——
LLM 靠「像不像真的」就能判断。

| 条件 | 整题全对 |
|---|---:|
| 给结论 | 82.6% |
| 不给结论 | 69.6% |
| 全随机期望 | ~5% |

69.6% 远高于随机 5%，说明泄漏。

## 二、改造方式

每条要点从自然语言改成六元素组合：

```
<第N章「章名」> · <人物> · <地点> · <事件> · <情绪> · <物品>
```

例：

```
真：第2章「巧合还是阴谋」 · 陈默、老人 · 求知园 · 同名同姓 · 虔诚 · 《工程控制论》
假：第3章「身份谜团」 · 陈默 · 舱室 · 结果是5人 · 一丝诡异 · 电子徽章  <- 错:物品
```

## 三、三条硬规则

| 规则 | 说明 |
|---|---|
| 真点 | 六元素全部符合原文（逐字可查；情绪必须是原文连续子串）|
| 假点 | 只错一个元素，其余五个各自为真但不与同题真点重合 |
| 孪生对 = 0 | 真/假点不得「仅差 1 元素」，否则模型可比对「这两个必一真一假」反推答案 |

孪生检查实测：92 题 / 406 个真/假配对中，仅 2 对是孪生（0.5%）。

## 五、待验证

本版尚未有第三方读数。验证要点：
1. 闭卷（不给材料）：期望接近随机（4 点全蒙对 6.25%，5 点 3.125%）；
2. 开卷（给全文）：期望 >= 90%；
3. 注意测法：如果 prompt 里写「你没有原文」，模型会拒答（「我不能凭空核对」）——
   验证端需明确要求「即使没有原文也请凭印象判断」；
4. 孪生检查：mh6_1_v2_audit.json 里记录了每个假点错的是哪个元素。

## 六、边界

1. 92 题由 5 个子代理分批改造（每题回原文逐章核对）；
2. 事件类错点（语义级）无法纯字符串断言，靠 evidence 行号人工核；
3. 少数情绪是「该章可查」而非「与事件同一句」（30-50 字硬约束下的取舍）；
4. 只测「认出」，不测「自由复述」。
