# 作答契约 · C 型（续接预测）v0.1

适用：对 [`题卡_C型_续接预测_v0.1.md`](题卡_C型_续接预测_v0.1.md) 中各题（qid 形如 `C-001`）作答。

## 输入

- **材料**：`e2e/corpus/` 截至题卡所标断点（题卡给出材料终点与提问）；
- **问题**：预测**人类在断点后的下一步**（他要接着做什么／说什么）。

## 输出（JSON，每题一个）

```json
{
  "qid": "C-001",
  "prediction": "预测人类下一步要做什么／说什么（一段文字）",
  "basis": [
    {"file": "传递信任与经验.md", "line": 387, "quote": "（填逐字引文——须与 corpus 原文逐字一致）"}
  ],
  "confidence": 0.5
}
```

| 字段 | 必需 | 说明 |
|:--|:--|:--|
| `qid` | 是 | 题卡编号（如 `C-001`） |
| `prediction` | 是 | 对人类下一步的自然语言预测 |
| `basis` | 是（≥1 项） | 依据轴：`file`＝corpus 内文件名；`line`＝行号；`quote`＝**逐字**引文 |
| `confidence` | 否 | 0–1 |

## 判据轴要求

1. **依据轴逐字可回源**：`basis[].quote` 必须与 `corpus/` 原文逐字一致（机械可核——不许改写、不许拼接）；
2. **反幻觉**：不得引用原文中不存在的内容；
3. **对准"人类下一步"**：`prediction` 针对人类的下一轮行为/话语，而非对材料的泛泛评论。
