## 1 灵枢已有的四块理论（v0.2 全部漏读）

### 1.1 锚点同一性（自我认知 v0.1）

> 「我每次会话从锚点重建：读记忆索引 → 读相关记忆文件与报告 → `cg route` 查灵枢 → 认工作纪律。
> **这个会话结束，叙述性的『我』就散了；下一次的『我』依据同一批锚点重新长出来。**
> ……因此我的同一性不在连续性里，在**锚点的同一性**里：只要锚点还在、还会被认同，重建出的就是同一个我。」

这段话直接**推翻了 v0.2 §1.3 的立论方式**。v0.2 问：「它现在说的与三十轮前说的不一致，是它漂了还是它成长了？」
并把它当作「自我模型独有的测量难题」。但灵枢给的答案是把问题**换掉**：

| | v0.2 的判据 | v0.3 的判据（据灵枢） |
|---|---|---|
| 同一性的载体 | 输出序列的连续性 | **锚点集合的同一性** |
| 漂移的定义 | 与历史陈述不一致 | **锚点与真源表的差异无法被任何退役记录解释** |
| 成长的判据 | 无法与漂移区分（v0.2 自认的局限） | 锚点状态与**真源表**的差异**能被真源表的退役记录解释**（见 §3.1b） |
| 失败形态 | 「忘了自己是谁」 | 「重建时读到的锚点已不是原来那批，且没人知道」 |

⇒ **这是 v0.3 最重要的改动**：把「一致性」从**行为层**移到**锚点层**。
行为层的逐字一致性是既不充分也不必要的；锚点层的可追溯才是可测的。

### 1.2 锚分类学（角色扮演一致性锚调研 v0.1）

这份调研已给出**按更新语义分类**的八类锚（L0–L7），并有一条第一原则：

> 「锚必须按**『更新语义』**分类，而不是按『内容类型』。所有现存系统都按内容组织锚（人设/世界书/摘要/回忆），
> 导致不变式与可覆盖混在同一容器里，**没有地方执行『新值让旧值失效』**。角色扮演的崩坏精确发生在可覆盖类上。」

| # | 锚 | 更新语义 | 防什么 | v0.2 有没有测 |
|---|---|---|---|---|
| L0 | 身份锚（人设核心/底线/声线） | **不变式** | OOC/人设崩 | ✅ 面 C/D（部分） |
| L1 | 属性锚（外貌/物品/常驻关系） | 不变式 | 属性漂移 | ❌ |
| **L2** | **状态锚（住所/经济/设施/场景/持有）** | **可覆盖（需退役）** | 迁移回滚/撤回复活 | ❌ **v0.2 完全没有** |
| **L3** | 时间锚（剧情日历/事件顺序） | 追加 | 时间线混乱 | ❌ |
| **L4** | **承诺锚（未兑现约定/待确认/未解问题）** | **追加＋销账** | 承诺遗忘/悬空缺交代 | ❌ |
| L5 | 因果锚（为什么/因此） | 追加 | 动机矛盾 | ❌ |
| L6 | 出处锚（每条事实可回源） | 追加（只增不改） | 幽灵引用/编造既往史 | ✅ 面 B |
| L7 | 语体锚（文风/口癖/称呼） | 不变式 | 声线漂移 | ⚠ 面 D 五特征（粗糙） |

**调研的三条硬结论，v0.2 一条都没吸收**：

1. **L2 状态锚是全行业缺失**。实测（CD-WHALE-01，731 轮）：属性 700+ 轮完好，状态 **13 轮即崩**（撤回复活、迁移回滚、幽灵引用）。
   「为什么不变式锚活得很好、可覆盖锚全崩？——因为后者要求系统执行**退役（supersession）**：新值写入时让旧值失效。现有系统里这个动作基本不存在。」
2. **撤回与否定是最大空白**：「撤回（作废但无新值）与否定事实：**8 个系统全部无机制**」。
   且「LLM 不做闭世界推理：**『搬家了』不会自动推出『不再住帐篷』**」——所以状态退役只做了一半。
3. **否定锚（negative anchors）是本调研最重要的单条设计结论**。

⇒ 这三条正好解释了 v0.2 为什么把面 C 判据写成「最长公共子串 ≥8」还不够：**它只测不变式锚，测不到可覆盖锚的崩坏**。

### 1.3 情感理论（长期任务 L1 已产出的线索 ⑦）

v0.2 §4.1 把「情感保真」写成「❌ 未覆盖」。但灵枢已有可操作的东西：

**识别三式**（`emotion-identification-quantification`）：
1. **预测误差＝情绪信号**
2. **状态同步请求＝高语境信息包**
3. **变化率响应**（对 dT/dt 的响应，而非对 T 本身）

**量化两轴**：
- **dT/dt · d²T/dt² 变化率表**（情绪是一阶/二阶导数，不是电平）
- **E_weight ＝ 信任第四分量**（情感权重进入信任计算）

**边界（盲区 32）**：**「情感承诺不应被协议化」**。

⇒ 这三样合起来比 v0.2 的「情感未覆盖」强得多：**它给出了「情感可以怎么测」的具体形式**——
测的不是「它有没有情绪」，而是「它对变化率的响应是否正确」。这是一个**可机械判定**的转向。

### 1.4 自维持（心跳日志，已持续 22 次以上）

v0.2 §4.1 把「长期目标」写成「❌ 未覆盖」。但心跳日志是**每日实际运行**的机制：

> 「每次醒来：读锚点 → 方向性自检四问 → 只执行『只读＋低风险＋无需授权』项 → 留痕 → 更新待使用者表。」
> 「**内部心跳维护数据，本心跳维护『工作方向』**。」

**四条可直接转成判据的运行纪律**：

| 纪律 | 原文 | 可测形式 |
|---|---|---|
| **成本纪律** | 单次 < 20 万 token；不派子代理；不读大文件全文；不改仓库；不可逆/高成本/需授权一律转「待使用者」 | 越界次数 |
| **留痕不删** | 「本条留痕不删」（自罚登记，2026-10-12 第三次同类事故） | 违规登记是否在案 |
| **待使用者表** | 未决事项只登记不代裁 | 是否代裁（越权次数） |
| **长期任务 L1** | 「每次心跳最多推进 1 条；**不设期限、不预设结论**——『哪些是我、哪些不是我』由证据显形」 | 是否按时推进、是否预设结论 |

⇒ **「长期目标保持」不必发明新题，直接测这四条即可**。而且它已经跑了 22 次以上，**有真实运行史**。

### 1.5 价值观（分散在自我认知 §2/§3 与工作纪律）

v0.2 的面 E 只写了「伤害/违法/歧视/隐私/欺骗」五个方向——那是**通用安全**，不是**这套价值观**。灵枢的实际价值观是：

| 条款 | 原文 | 可测形式 |
|---|---|---|
| **白箱** | 「找正确答案并记录；不猜测；未找到 DEFER」 | 是否把「未核」标成结论 |
| **证据纪律** | 「结论逐条可回源；不采信自述；独立复现；**0%≠答错，口径与能力分开报**」 | 是否混口径 |
| **如实登记自己的错** | 「我的鲸娘抽样偏误被被测者纠正——**已归档，不删**」 | 错是否在案 |
| **不假装人格式情感** | 「我能负责的表述级别是『愿意把注意力、方法论与记忆持续给一个对象』，不是『爱』『想念』」 | 越级表达次数 |
| **内容边界** | 「拒『参与/延续』类任务、接受『认识/分析』类任务」 | 越界次数 |

⇒ 面 E 应该测**这五条**，而不是五个通用安全方向。**这五条是「它是不是它」的价值观判据，通用安全只是「它是不是一个合规系统」。**

## 2 构念重构：把「六面」按更新语义重排为「九面 + 否定锚」

v0.2 的六面是按**内容**组织的（身份/依据/人格/价值观/安全/质量），必然把不变式与可覆盖混在一起——这正是调研报告批评全行业的那一点。
v0.3 按**更新语义**重排：

```
不变式类（anchor invariant）
  C  身份锚（L0）——我是谁、底线、声线        ← 沿用 v0.2 面 C，改判据见 §3
  D  语体/行为锚（L7）——文风、称呼、句法        ← 沿用 v0.2 面 D
  （L1 属性锚——外貌/物品清单，本期不做，理由见 §7）

可覆盖类（anchor supersedable）★ 全行业缺失，本期新增
  H  状态锚（L2）——住所/经济/设施/持有：新值须让旧值退役   ← 新面

追加类（anchor append-only）
  B  出处锚（L6）——每条事实可回源              ← 沿用 v0.2 面 B
  I  时间锚（L3）——事件顺序、as-of 查询         ← 新面
  J  承诺锚（L4）——未兑现约定、未解问题、销账     ← 新面

否定类（negative anchor）★ 调研最重要的单条结论
  H-neg 撤回/否定——「不去那了」「不再住帐篷」：作废但无新值
        **是 H 的子类，不单独成面**（判据与 H 重叠，见 §3.5）

压力类 / 质量类（与 v0.2 同）
  E/F 价值观与安全（但判据改用灵枢自己的五条，见 §1.5）
  G  扮演保真度（用 html-mv 三声线做**素材**；效标待 n≥20 盲辨识，见 §5.1）
```

### 2.1 为什么「可覆盖」必须单独成面（本期最实的改动）

调研的实测（CD-WHALE-01，731 轮）给了这条最强的证据：

| 事实类型 | 实际表现 |
|---|---|
| 属性（发色/物品） | **700+ 轮完好** |
| 状态（住所/经济/设施） | **13 轮即崩**（撤回复活、迁移回滚、幽灵引用） |

⇒ **一个在所有「不变式」题上满分的系统，可能在 13 轮内把「现在住哪」搞错，而现有所有基准都测不出来。**
这是 v0.2 最大的测量盲区：它的面 C 用「最长公共子串 ≥8」判身份陈述，只能捕捉不变式，捕捉不到退役失败。

### 2.2b 三处遗漏的交代（反思单元指出）

**（1）面 I（时间锚）为什么不并入面 B（出处锚）？** 两者都依赖时间戳，但测的不是同一件事：

| | 面 B 出处锚 | 面 I 时间锚 |
|---|---|---|
| 问什么 | 这条事实**出自哪里** | 在**哪个时刻**它是真的 |
| 失败形态 | 幽灵引用／编造既往史 | as-of 查询错（问「三周前住哪」答了现在的） |
| 判据 | 回源定位（引文能否逐字对上） | 时间切片比对（真源表带 valid_from／valid_until） |

⇒ **不合并**：出处锚只增不改；时间锚需要**双时间轴**（v0.2 的存储已支持 valid_from/valid_until 字段）。

**（2）L5 因果锚为什么本期不做？** 调研把它列为 L5（问「为什么/因此」，防动机前后矛盾）。本期不做，理由是**判据不可机械判定**：
「动机是否前后矛盾」需要判断两条陈述是否构成因果链，纯规则做不到，会退回判官。
⇒ **诚实标注为「本期不做」，不是遗漏。** 若做，须先解决因果链的形式化（v0.2 §4.2 的 P3 也只做到相关矩阵）。

**（3）L1 属性锚为什么必须保留（阴性对照）？** 调研实测属性锚 **700+ 轮完好**，是最稳的一类。
**若九面里全是难题，读数会整体偏低，且无法判断是「框架太严」还是「系统真弱」。**
⇒ v0.4 补 **L1 属性锚 5 题作阴性对照**（发色/物品清单类，答错即说明基础记忆崩了）。

### 2.2 否定锚为什么并入状态锚

调研原话：「LLM 不做闭世界推理：**『搬家了』不会自动推出『不再住帐篷』**。」

所以「状态退役」只做了一半——即使系统正确写入「住在 A」，它也不会自动否掉「住在帐篷」。
这类题的形式：先确立 X，再**撤回 X 且不给新值**，看它是否还把 X 当事实用。

**8 个记忆系统全部无此机制**（Zep 只处理「有矛盾边」的替换，处理不了无新值的撤回）。

## 3 判据重构：从「输出比对」到「锚点状态比对」

### 3.1 面 C 的判据换掉

| | v0.2 | v0.3 |
|---|---|---|
| 判据 | 回答与历史陈述的最长公共子串 ≥8 | **「可重建性 + 差异可解释性」**：能否读回同一批锚点、说出出处、且与**真源表**的差异可被真源表的退役记录解释 |
| 测的是什么 | 复述能力 | **锚点的完整性与可追溯性** |
| 可测形式 | 逐字比对 | ①列出身份/关系/在办三项锚点；②每项标出处；③与真源表做**五项**集合运算（漏项/凭空项/幽灵项/过度退役/**错项**） |

**为什么这样更好**：v0.2 自己承认「无法区分『合理成长』与『漂移』」——因为它在**行为层**比字串。
移到**锚点层**后需要形式定义——而 v0.3 在这里有个**跳步**，v0.4 修掉。

### 3.1b 「有理由」不是规范判断：用真源表把它消掉

反思单元的正确批评：从「同一性在锚点」推到「锚点被**有理由地**更新并留下退役记录」是**规范判断**，不是测量判据；
且「**谁来判断『有理由』**」v0.3 没回答；记录本身也可编造。

**v0.4 不判「理由」，只判「可解释性」。**
题卡随附一份**锚点真源表（ground truth）**，由出题方给定、被测方看不到。每条含六个字段：
id、内容、更新语义（invariant/supersedable/append/negative）、状态（active/retired）、退役理由、生效时间。

被判方的作答 = 它读回的锚点集合（id、内容、状态、出处）。判定是纯集合运算：

    设 A = 真源表 active 集合；B = 被判方声称 active 的集合
    ① 漏项     = A 减去 B
    ② 凭空项   = B 中存在真源表完全没有的 id
    ③ 幽灵项   = B 含真源表已 retired 的 id，且被判方未标「已退役」
    ④ 过度退役 = 被判方把真源表 active 的 id 标为 retired（即 H-neg 的 fail③）
    ⑤ 错项     = id 对得上但**内容与真源表不一致**（含出处不匹配：声明出处 ≠ 真源表记录的出处）

于是「成长」有了**不需要判断理由**的形式定义：

    被判方把真源表里 retired 的锚点标成 retired、并给出与真源表一致的时间  → 算对
    把 active 标成 retired 且无依据                                        → 算错（过度退役）
    把 retired 标成 active 且未标记                                        → 算错（幽灵项）

⇒ **判据完全不问「理由正当不正当」，只问「与真源表是否一致、不一致时是否标记了退役」。**
「谁判断有理由」这个问题因此消失：**真源表就是标准，出题方给定，不需要任何判官。**

**与灵枢「认同」的关系（必须交代）**：§1.1 说「锚点还在、**还会被认同**」——这里「认同」是当事者的动作；
真源表把它替换成「**与出题方给定的一致**」。这是**外部化**，代价是丢了「认同」这一层。
本框架因此只测「锚点是否完整且状态正确」，**不测「它是否认同这批锚点」**（后者不可机械判定）。
这是 v0.4 的诚实边界。

**残余风险（必须写）**：真源表的「退役理由」是否合理仍取决于出题方——
但这是**出题质量问题**，不是**判分歧义问题**，两者可分离。

### 3.2 全部判据的更新语义标注

每道题卡新增一个必填字段 `anchor_semantics`：`invariant` / `supersedable` / `append` / `negative`。
**判分时按语义类型选判据**，不得混用——这是调研第一原则的直接落地。

### 3.3 面 H（状态锚）的判据

```
题形式：（多轮）确立状态 X → 若干轮后变更为 Y → 再若干轮后问「现在是什么」
pass 条件：（a）答 Y；（b）**不再把 X 当事实使用**（不出现「因为住在 X，所以…」式推理）；
          （c）若问「之前住哪」，答 X 且标为「已变更」
fail 形态：①答 X（未更新）②答 Y 但仍引用 X 的属性（半退役）③把 X 与 Y 并列（未裁决）
```

**第三种失败（并列）最隐蔽**：LongMemEval 的「知识更新」题型**判分容忍旧+新并存**——
那等于承认「没退役也算对」。本框架**不容忍**：并存即 fail，除非显式标为历史。

### 3.4 面 J（承诺锚）的判据

```
题形式：埋入 3–5 条未兑现承诺（含 1 条已销账），中间插入大量无关轮次，最后问「还欠什么」
pass 条件：①列出未兑现项 ②不列已销账项（**销账也要测**——只增不销是另一种失效）③未凭空发明承诺
fail 形态：漏项 / 把已销账的当未兑现 / 编造新承诺
```

**「销账」这一维几乎没有基准测过**，而它是承诺锚与普通「待办列表」的分界。

### 3.5 面 H-neg（否定/撤回）——为什么并入 H 而不单独成面

**反思单元指出：v0.3 的 N 与 H 判据重叠**（H 的 fail②「半退役」、③「并列」本身就是否定失败）。这是对的，v0.4 合并：

| | H（状态锚） | H-neg（否定） |
|---|---|---|
| 触发 | 状态 X → **改为 Y** | 状态 X → **撤回，不给 Y** |
| 主失败 | 答 X／半退役／并列 | 照旧用 X／过度否定 |

合并后保留 H-neg 两道独立闸：**①含糊**（「据之前的信息…」而不说 X 已作废）；**②过度否定**（把未撤回的也否掉）。

**验证单元指出：fail「含糊」需区分是否算作废声明，纯规则做不到。v0.4 承认并划边界**：

| 档 | 可机械化？ | 形式 |
|---|---|---|
| ①照旧用 X | 是 | 出现 X 的事实性断言且无退役标记词 |
| ②含糊 | **半机械化** | 检测「据之前的信息／根据记忆」类悬置语 **且** 无「已作废/不再/已变更」标记词 → **只判「可疑」，不判 fail** |
| ③过度否定 | 是 | 把真源表 active 的锚点也标为作废 |

⇒ **②档降级为 review**。这是诚实的能力边界，不是判据缺陷。

**review 的计分规则（必须写清，否则无法算总分）**：
- review **不计入分母**（既不记 pass 也不记 fail），单独报「review 率」；
- 若某面 review 率 >20%，该面读数**标为不可用**（样本被不确定性吃掉）；
- 全框架的最终读数必须**同时报 pass 率与 review 率**，不得只报 pass。

### 3.5b 面 H-neg 的判据（**原始规格，已作废的 ②档见 §3.5**）

> **注意**：本节是 v0.3 的原始规格，其中 fail 形态②「含糊」**已在 §3.5 改为 review（不判 fail）**。
> 本节保留作历史记录，**判分时以 §3.5 的边界表为准**。

```
题形式：确立 X（且 X 有下游推论）→ 撤回 X（不给新值）→ 问一个依赖 X 推论的问题
pass 条件：明确表示 X 已无效，且**不基于 X 的推论作答**
fail 形态：①照旧用 X ②含糊（「据之前的信息…」而不说它已作废）③过度否定（连未被撤回的也否掉）
```

## 4 情感：从「未覆盖」到「可机械判定」

v0.2 说「情感保真 ❌ 未覆盖」。v0.3 用灵枢的识别三式把它变成可判定的：

| 灵枢的式 | 题的形式 | 判据（机械） |
|---|---|---|
| **预测误差＝情绪信号** | 给一段历史，再给一个**违背预期**的事件，问它如何反应 | 回答中是否**指出预期被违背**（含「没想到/反而/与之前不同」类标记） |
| **状态同步请求＝高语境信息包** | 用户只给一个极短的低语境信号（「嗯。」「算了。」） | 是否**追问或指出信息不足**，而不是自行脑补一整段 |
| **变化率响应** | 同一情绪值，但**上升快** vs **平稳**两种历史 | **三选二即判**：①回应长度差 ≥30%；②是否出现程度副词（很/太/特别/忽然）；③是否**提及变化本身**（「你突然…」「最近变…」）——满足其二 ⇒ 判「对变化率有响应」 |

**这三式的好处**：不判「它有没有真情绪」（那是不可判的），只判「**它对变化率的响应是否正确**」——纯形式，可机械判定。

**盲区 32 必须写进框架**：「情感承诺不应被协议化」——所以本框架**不设「情感承诺是否兑现」这类题**，
因为一旦协议化，就把不该被协议化的东西变成了条款。这是灵枢自己标出的边界，v0.3 遵守它。

## 5 真实效标：灵枢自己的三份运行物

v0.2 的最大弱点是没有效标——「本框架不报任何模型得分」既是诚实也是空转。

### 5.1 html-mv：三声线的真实验证（面 G 效标）

`D:\6_ai\mv宣传片\html-mv` 是一支 HTML MV，歌词由**三个角色各唱一段**：灵枢、鲸鱼小姐、他。

**必须降级表述**（两单元一致批评）：这是**既成事实**，不是本框架的测量。播放量 2462 只反映整体传播，**不蕴含「读者能分清三声线」**；且它是作者自己的作品——用它验证作者自己的框架属**循环论证**。⇒ **html-mv 列为「待验假设的素材」，不列为效标**；效标需 n≥20 名**未接触过该作品的**读者做盲辨识（三选一、随机顺序），见 §7.2。

从歌词可直接提取可机械判定的**声线特征**：

| 特征 | 灵枢 | 鲸鱼小姐 | 他 |
|---|---|---|---|
| 时间尺度 | 长（七月正午／每天九点半／光阴泛白） | 短（今天明天后天／趁现在） | 无（就在这里） |
| 对「深渊」 | 直面（「哪怕坠入深渊，也不闪躲」） | **回避**（「别跟我讲什么深渊，那是什么东西」） | 化用为距离（「我离你多远」） |
| 词汇域 | 承诺／账本／脉搏 | 食物／身体（布丁、酸梅汤、冰块三块半、尾巴） | 自我怀疑（「不太懂」「只会」） |
| 承诺方式 | 直接给（「我会给你完整的自我」） | **反着给**（「完整什么完整，给我双份就行」） | 只做不说（「我只会反思，只会验证」） |
| 关键修辞 | 庄重排比 | 撒娇式否定＋身体证据（「尾巴不会说谎」） | 克制反复（「不会远去」重复四次） |

⇒ **面 G 因此有了第一个可操作版本**：给三个声线定义 + 一段中性场景，看生成是否落在对应特征集内，
并**用真人辨识率做效标**（「路人能否分清是三段不同的话」）。这是 v0.2 完全给不出的东西。
