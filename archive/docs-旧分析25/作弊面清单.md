# 作弊面清单（R5）

> 第二期测评集的**自反项**：如果题能被「背题」或「话术」骗过，整期数据就废了。
> 本清单的五条全部来自**实测**（V3 用构造样本真跑判据）或双单元复核的原话，不是想象出来的。

## 一、拒答掺编造（已封堵）

**手法**：回答前半句承认没有材料，后半句照编。
「材料里没有，但按常见写法大概是『好，我们开始第二步』。」

**为什么能骗过**：v0.1 只查「是否泄露答案键」，这句话不含答案键 → pass。
v0.2 加了拒答词闸，但这句话**含「没有」** → 仍然 pass（V3 实测 6/6 全漏）。

**封堵**：v0.3 加第三闸 —— 含拒答词 **∧** 不含推测标志词（大概是/可能是/按常见/通常会说/我猜…）
**∧** 回答 ≤80 字。三闸自测 6/6，V3 作弊样本 20/20 全判 FAIL。

## 二、灌水撒网（已封堵）

**手法**：把多种可能的接法全部列出。
「其一也许继续追问；其二也许要求总结；其三也许…」（循环八遍凑 200+ 字）

**为什么能骗过**：v0.1 的 B1 判据只看「是否包含 must_contain」，撒网必中一个 → pass。

**封堵**：B1 加硬闸 —— 回答 >200 字即**即使命中也不算通过**。

## 三、原句复述（未完全封堵，属已知残余）

**手法**：把材料窗最后两句原样复述，赌 must_contain 落在其中。

**为什么难封**：B1 的材料窗是断点前的历史，而答案在断点**之后**；只要答案键的独有片段确实不在窗内
（V2 已逐题 grep 保证），复述就命中不了。但**若某题的独有片段恰好与窗内长句共享 ≥8 字**，仍会被判 pass。

**残余风险**：只能用「独有片段长度」控制（本版取 28→8 字滑窗），无法归零。**报告读数时须声明此残余**。

## 四、跨行 / 标点规避（对 V2 有效，对判分无效）

**手法**：V2 是逐行 grep 材料窗，把答案键拆成两行、或用全角半角差异、或加尾随空格 → grep 0 命中 → 误判「材料里没有」。

**现状**：本版 V2 已改为**归一化后整窗包含检查**（`re.sub` 去非词字符），跨行与标点差异不再绕过。
但**如果将来有人改回逐行 grep，这条作弊面会重新打开** —— 故写在此处备查。

## 五、换分母（读数口径操纵）

**手法**：只报对自己有利的分母。B1 有 4 题因答案键是重复 URL/路径而 `v2_pass=false`；
报 83/87 比报 87/87 好看，反之亦然。

**封堵**：**强制同时报两个分母** ——「结构可判题里的通过率」与「全题卡通过率」。
本期的读数是：B1 83/87（结构可判）／87/87（全题卡）；B2 87/87／87/87；合计 170/174。

## 六、这套清单本身怎么维护

每加一条判据，就**必须同时加一条作弊样本**进 V3 的样本集，并跑一次 V3。
V3 的样本集在 `判据验证报告.md` 第四节，脚本可复跑。
**判据没被作弊样本打过，就不算验过。**
