# 横比口径 v1.0（P2 产出）

> **本文件规定：两组插件读数在什么条件下可比、什么条件下不可比、报数时必须附带什么。**
> 依据：双单元 P1 复核的判词——「156 仍偏宽」「B1 全量挂起不算解决」「判据版本主导 26.5pp」。

## 一、冻结前提（缺一不可）

| # | 前提 | 现状 |
|---|---|---|
| 1 | **判据版本冻结** | ✅ `e2e/tools/judge.py` v1.1，SHA256 `4643d75a5cf8845b`，变更记录见 `judge_CHANGELOG.md` |

**规则**：不同 `judge_version` 之间的读数**不可比**。判据改动 = 升版 + 重跑 `check_judge.py` + 同步 320 题。

## 三、独立性约束（**这是 156 这个数字的硬限制**）

```
B1 + B2 = 166 题，但共用 87 个断点 ⇒ 独立样本 87，不可相加
H 的 3 道真状态锚题全部来自第八话同一段落 ⇒ 独立样本 1，不可当 3
⇒ 「156 题」是**名义题数**，不是独立样本数
```

**报数时必须同时报**：`名义题数` / `独立簇数` / `判据版本`。

## 四、三种可报的读数（按可信度）

### A 级：可横比（推荐）

```
面：B2 / C / E / F / L1
合计：153 题（87+39+10+10+7）
限制：C 只测检索；L1 是阴性对照（题偏易）
```

**报法**：分面报通过率 + 各自独立簇数 + 判据版本 `v1.1`。
**不做**：不把五个面合成一个「总分」——它们测的东西不同（拒答/检索/价值观/安全/对照）。

### B 级：单列参考（不进总分）

```
D（45）：五特征可判，但人设不自然
H 的 3 道真状态锚：测对了，但同一段落不独立
```

### C 级：不计数

```
B1（79）：猜真实下文
J（17）：需语义判断
H 的 15 道读表题
```

## 五、必须与读数一起报的五件事

1. **判据版本**（`v1.1`）与其 SHA256；
2. **名义题数**与**独立簇数**；
3. **每面的 review 率**（若 >20%，该面读数标不可用）；
4. **排除题数与原因**（当前 8 题：4 超长窗 + 2 答案不在窗内 + 2 推不出）；
5. **空缺面声明**（I 时间锚 / G 扮演保真度 / 情感三式 = 0 题，**不计入任何总分**）。

## 六、禁止事项

1. **禁止**把 B1 与 B2 相加报 166 题——它们共用断点；
2. **禁止**把 156 当成「独立样本数」——它是名义题数；
3. **禁止**跨判据版本比读数；
4. **禁止**只报 pass 率不报 review 率；
5. **禁止**把 D 或 J 的分数混进总分；
6. **禁止**宣称「九面 320 题」——准确说法是「5 面 153 题可横比 + 45 题单列 + 111 题不计数 + 3 面空缺」。

## 七、这份文档自己的局限

- A 级的 153 题里，C 只测检索、L1 偏易——**它们拉高读数的可信度仍需实证**；
- 独立簇数是用 `source_card` / `source_file` 粗代的，**不是真正的语义独立性分析**；
- 未做「同源降权」的定量方案（如按簇加权），只做了「不相加」的硬约束。
