## 引用时必须同时报

1. **闭卷 φ 的两个口径**：保守（没把握就答否）φ=0.000 / 激进（强制给答案）φ=0.348；以保守报主读数，激进作上界；
2. **开卷材料口径**：只给所引章节 ≠ 给全文 ≠ 端到端系统；
3. **模型与配置**：`deepseek-flash` + `thinking=disabled` + `temperature=0`；
4. 单次运行，无重复测量。
